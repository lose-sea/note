# 第五部分：Block 捕获对象时要注意什么？

Objective-C 中常见的对象变量，例如 `NSString *`、`NSArray *` 和自定义模型对象，也可以被 Block 使用。

## 5.1 捕获对象指针

```
NSString *name = @"Tom";

void (^myBlock)(void) = ^{
    NSLog(@"%@", name);
};

myBlock();
```

输出：

```
Tom
```

这里的 `name` 是一个指针变量，指向字符串对象。对于普通的局部自动变量，Block 捕获的是该指针当时的值。

需要区分两个概念：

+ 指针变量本身：保存对象的地址。
+ 指针指向的对象：实际的字符串、数组或模型对象。

捕获指针，不等于复制整个对象。

## 5.2 修改指针变量与修改对象，是两件事

假设有一个可变数组：

```
NSMutableArray *array =
    [NSMutableArray arrayWithObject:@"A"];

void (^myBlock)(void) = ^{
    [array addObject:@"B"];
};

myBlock();

NSLog(@"%@", array);
```

输出：

```
(
    A,
    B
)
```

这里 Block 虽然捕获了局部指针变量的值，但仍然可以通过该指针调用 `NSMutableArray` 的方法，修改它指向的可变数组对象。

这并不等于在 Block 内给普通局部变量 `array` 重新赋值。

例如：

```
NSMutableArray *array =
    [NSMutableArray array];

void (^myBlock)(void) = ^{
    array = [NSMutableArray array];
};
```

这种直接重新赋值的写法，对于普通局部变量仍然会编译报错。

核心区别是：

+ `[array addObject:@"B"]`：修改对象的内容。
+ `array = ...`：修改局部指针变量保存的值。

前者通常允许，后者需要考虑变量的捕获规则。
