# 导航栏和工具栏

iOS13 之后，废弃了之前直接修改 navigationBar 属性的写法，开始使用 UINavigationBarAppearance 统一管理导航栏外观

iOS13 之前：
通过直接修改 UINavigationBar 的属性（如 barTintColor、tintColor、titleTextAttributes）来控制导航栏外观，属于“零散属性式配置”。

iOS13 之后：
引入 UINavigationBarAppearance，通过创建外观对象统一配置（背景、标题、按钮等），再整体应用到导航栏，属于“集中式外观管理”。



旧写法：一个属性一个属性改（零散、容易冲突）

新写法：先定义一套外观（appearance），再一次性应用（统一、可控） 

iOS13 之后，导航栏样式从“直接操作 UI 属性”转变为“通过外观对象统一管理”，是 UIKit 在 UI 设计上的一次结构升级。



| 功能     | 旧写法（已过时）    | 新写法（推荐）                     |
| -------- | ------------------- | ---------------------------------- |
| 背景颜色 | barTintColor        | appearance.backgroundColor         |
| 按钮颜色 | tintColor           | appearance.buttonAppearance        |
| 标题颜色 | titleTextAttributes | appearance.titleTextAttributes     |
| 透明效果 | translucent         | configureWithTransparentBackground |
| 阴影线   | shadowImage         | appearance.shadowColor             |





在设置完成之后一定要进行应用 , 才能起作用

```objc
UINavigationBar *navBar = self.navigationController.navigationBar;

navBar.standardAppearance = appearance;
navBar.scrollEdgeAppearance = appearance;
navBar.compactAppearance = appearance;
```

完整版写法

```objc
UINavigationBarAppearance *appearance = [[UINavigationBarAppearance alloc] init];

// 不透明背景
[appearance configureWithOpaqueBackground];

// 背景色
appearance.backgroundColor = [UIColor blackColor];

// 标题颜色
appearance.titleTextAttributes = @{
    NSForegroundColorAttributeName: [UIColor whiteColor]
};

// 按钮颜色
appearance.buttonAppearance.normal.titleTextAttributes = @{
    NSForegroundColorAttributeName: [UIColor whiteColor]
};

// 应用
UINavigationBar *navBar = self.navigationController.navigationBar;
navBar.standardAppearance = appearance;
navBar.scrollEdgeAppearance = appearance;
navBar.compactAppearance = appearance;
```

### 三种 Appearance 应用的含义

###  `standardAppearance`（标准状态）

 **最常见的状态**

+ 导航栏处于正常显示
+ 内容没有滚动到顶部边缘
+ 一般页面默认就是这个样子

 例子：

+ 普通页面刚打开
+ 列表没有滑到最顶部

------

###  `scrollEdgeAppearance`（滚动到边缘时

 **滚动到顶部时的状态**

+ 通常用于 `UIScrollView / UITableView`
+ 当内容“顶到最上面”时触发
+ 默认是 **透明效果（大标题常见）**

 例子：

+ iOS 大标题（Large Title）页面
+ 下拉到最顶部时导航栏变透明

------

###  `compactAppearance`（紧凑状态） **高度变小的时候**

+ 用在特殊场景：
  + 横屏（iPhone）
  + 小高度导航栏
+ 很少手动关注，但系统会用

 例子：

+ iPhone 横屏时的导航栏



```objc
navbar.standardAppearance = appearance;
navbar.scrollEdgeAppearance = appearance;
navbar.compactAppearance = appearance;
```

 **作用: 让导航栏在所有状态下都长一样**



# 工具栏

关闭工具栏的隐藏, 工具栏时默认隐藏的

```objc
    [self.navigationController setToolbarHidden: NO animated: YES];
```

为工具栏设置添加按钮 

```objc
// 添加按钮
UIBarButtonItem* item1 = [[UIBarButtonItem alloc] initWithTitle: @"点赞" style: UIBarButtonItemStylePlain target: self action: @selector(like)];

UIBarButtonItem* item2 = [[UIBarButtonItem alloc] initWithTitle: @"关注" style: UIBarButtonItemStylePlain target: self action: @selector(like)];

UIBarButtonItem* item3 = [[UIBarButtonItem alloc] initWithTitle: @"忘记" style: UIBarButtonItemStylePlain target: self action: @selector(like)];
```

将按钮加入到工具栏

**注意,参数要求 NSArray 类型, 需要将按钮包装到 NSArray 中** 

```objc
    // 加入工具栏
    // 参数要求是NSArray
    self.toolbarItems = @[item1, item2, item3];
```

按钮间距的设置

固定间距

```objc
UIBarButtonItem* space = [[UIBarButtonItem alloc] initWithBarButtonSystemItem: UIBarButtonSystemItemFixedSpace target: nil action: nil];
space.width = 100;
```

需手动设置按钮的间距的宽度, 适用于精细化操作



弹性间距 

```objc
UIBarButtonItem* flex = [[UIBarButtonItem alloc] initWithBarButtonSystemItem: UIBarButtonSystemItemFlexibleSpace target: nil action: nil];
```

会自动根据剩余的空间安排按钮的间距



在设置按钮的间距之后, 需要将间距与按钮同加入到 NSArray 中一起添加到工具栏
