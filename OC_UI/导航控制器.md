# 导航控制器



## 先创建一个窗口

```objc
    self.window = [[UIWindow alloc] initWithWindowScene: (UIWindowScene*)scene];
```

创建一个“窗口”（屏幕容器）

+ UIWindow = 整个 App 的显示载体
+ 所有界面最终都显示在它上面

## 创建第一个页面 (根视图控制器)

```objc
VCRoot* root = [[VCRoot alloc] init];
```

## 创建导航控制器

> 导航控制器主要用来管理多个视图控制器的切换
>
> 层级的方式来管理多个视图控制器 
>
> **创建控制器时, 一定要有一个根视图控制器** 

参数: 作为导航控制器的根视图控制器

```objc
UINavigationController* nav = [[UINavigationController alloc] initWithRootViewController: root];
```

## 将window 的根视图根视图作为导航控制器 

```objc
self.window.rootViewController = nav;
```

## 设置导航栏标题

```objc
    // 设置导航栏的标题
    self.title = @"根视图控制器";
    // 设置导航元素项目的标题
    self.navigationItem.title = @"title";
```

| 写法                 | 控制对象                   |
| -------------------- | -------------------------- |
| self.title           | 控制器级别的标题（推荐）   |
| navigationItem.title | 导航栏级别标题（精确控制） |

## 创建导航栏按钮 

创建导航栏左侧按钮

```objc
// 创建一个导航栏左侧的按钮
    // 参数 1: 按钮的文字
    // 参数 2: 按钮风格
    // 参数 3: 事件拥有者
    // 参数 4: 按钮事件
    UIBarButtonItem* leftBtn = [[UIBarButtonItem alloc] initWithTitle: @"左侧" style: UIBarButtonItemStyleProminent target: self action: @selector(pressLeft)];
    
    self.navigationItem.leftBarButtonItem = leftBtn;
```

创建一个系统风格的按钮 

根据系统风格来创建按钮 , 只需要指定风格样式, 系统风格的按钮内容或标题文字不能改变

> 参数1: 按钮风格
>
> 参数2: 事件拥有者
>
> 参数3: 按钮事件

```objc
UIBarButtonItem* rightBtn = [[UIBarButtonItem alloc] initWithBarButtonSystemItem: UIBarButtonSystemItemAdd target: self action: @selector(pressRight)];
self.navigationItem.rightBarButtonItem = rightBtn;
```



将任意类型的按钮添加到导航栏 

```objc
UIBarButtonItem* item03 = [[UIBarButtonItem alloc] initWithCustomView: label];
```



将多个按钮添加到到导航栏

```objc
    NSArray* arrayBtn = [NSArray arrayWithObjects: rightBtn, item03, nil];
    
    self.navigationItem.rightBarButtonItems = arrayBtn;
```

### 切换视图控制器 

通过按钮调用事件来切换视图控制器  

先在导航栏添加按钮

```objc
    UIBarButtonItem* next = [[UIBarButtonItem alloc] initWithTitle: @"下一页" style: UIBarButtonItemStylePlain target: self action: @selector(pressNext)];
    
    self.navigationItem.rightBarButtonItem = next;
```

通过事件来切换视图控制器 



在事件中, 先创建新的视图控制器, 然后切换

```objc
- (void) pressNext {
    // 创建新的视图控制器
    VCSecond* vcSecond = [[VCSecond alloc] init];
    
    // 使用当前导航栏的导航器对象
    [self.navigationController pushViewController: vcSecond animated: YES];
}
```

在这过程中, 系统做了 4 件事 

#### 加入栈

```
vcSecond 被加入 viewControllers 数组
```

------

#### 页面切换动画

```
从右往左滑入（默认动画）
```

------

#####  自动生成返回按钮

```
左上角 ← 返回
```

 这个按钮其实：

+ 来自 VCSecond 的 navigationItem
+ 内容是：上一个页面的 title（VCRoot.title）

------

#### 4️⃣ 当前页面变成 VCSecond

```
topViewController = VCSecond
```

### 返回上一个视图控制器 

弹出栈顶的视图控制器 (当前页面)  

```objc
[self.navigationController popViewControllerAnimated:YES];
```



也可以直接返回更视图控制器  

```objc
// 直接返回到根视图
    [self.navigationController popToRootViewControllerAnimated: YES];
```
