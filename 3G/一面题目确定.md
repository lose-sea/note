## 二维数组的"方寸之间"（12分）

**题目：**

```c
#include <stdio.h>
int main() {
    int a[2][3] = {{1,2,3},
                   {4,5,6}};
    int *p = a[0];
    int (*q)[3] = a;
    
    printf("%d\n", *(p + 3) + *(*(q + 1) + 1));
    printf("%d\n", *(a[1] - 1) + *(a[0] + 4));
    printf("%zu\n", sizeof(a + 1) + sizeof(*a));
    printf("%d\n", (p + 2)[1] - (*(q + 1))[-1]);
    return 0;
}
```



------

### 问题（12分）

1. **写出程序输出结果**（4分）
2. **逐个表达式分析**（5分）
   - `*(p + 3)` 访问的是哪个元素？为什么？ 
     - 访问的是 **`a[1][0]`（即4）**
     - 原因：`p` 指向`a[0][0]`，指针+1就移动一个`int`大小，+3偏移到第4个元素，在连续存储中即第1行第0列。
   - `*(a[1] - 1)` 为什么能访问到 3？这是否安全？
     - 因为二维数组在内存中是**连续线性**存储的，`a[1]` 指向元素`4`，减1后指向前一元素`3`
     - **安全性**：在本题中，`a[1] - 1` 仍在数组范围内（指向`a[0][2]`），因此是安全的；但若越界（如`a[0]-1`）则不安全，属于未定义行为。
   - `sizeof(a + 1)` 的结果为什么不是 12？
     - `sizeof` 是编译时运算符
     - 在表达式中，`a` 退化为指针，`a+1` 是指针类型（`int (*)[3]`），其大小固定为**指针大小**（8字节），与数组元素个数无关。
   - `(p + 2)[1]` 等价于什么形式的指针运算？
     - 等价于 `*(p + 2 + 1)`，即 `*(p + 3)`
   - `(*(q + 1))[-1]` 中的 `[-1]` 访问的是哪个元素？ 
     - 访问的是 **`a[0][2]`，即 3**
     - 因为 `*(q+1)` 是第1行首地址，`[-1]` 表示向前一个元素，即第0行最后一个元素。
3. **概念辨析**（3分）
   - `p` 和 `q` 的类型分别是什么？它们的步长各是多少？
     - `p` 类型：`int *`，步长 = `sizeof(int)` = 4字节
     - `q` 类型：`int (*)[3]`（指向含3个int的数组的指针），步长 = `3 * sizeof(int)` = 12字节
   - 二维数组在内存中是连续存储的吗？请用本题证明。
     - `p+3` 能访问到 `a[1][0]`，`a[1]-1` 能访问到 `a[0][2]`，说明行与行之间无缝隙，是线性排列的。
   - 如果数组改为 `int a[2][3] = {0};`，`sizeof(a+1) + sizeof(*a)` 的结果会变吗？为什么？
     - **不会变**
     - 因为 `sizeof` 在编译期求值，与数组内容无关；
       + `sizeof(a+1)` 仍是指针大小（8）
       + `sizeof(*a)` 仍是第一行大小（12）



### 题解

这里要说出三个输出中详细的计算过程

**分步推导：**

```c
// 第1行
*(p + 3) = 4              // p指向1，+3跳到4（跨行了）
*(*(q + 1) + 1) = 5       // q+1指向第1行，解引用得{4,5,6}首地址，+1取5
结果 = 4 + 5 = 9

// 第2行
*(a[1] - 1) = 3           // a[1]指向4，-1指向3（跨行往前）
*(a[0] + 4) = 5           // a[0]指向1，+4跳到5
结果 = 3 + 5 = 8

// 第3行
sizeof(a + 1) = 8         // a+1退化为指针
sizeof(*a) = 12           // *a是a[0]，3个int = 12字节
结果 = 8 + 12 = 20

// 第4行
(p + 2)[1] = 6            // p 是指针数组,p表示的是第一行的第一个元素 1
							//( p + 2)[1]是p 先后移动 3 个int,指向 4
							
           
                          
(*(q + 1))[-1] = 3        // q+1指向第1行{4,5,6}，解引用后指向4，[-1]取3// q是数组指针,指向第一个数组第一个元素
							// (q + 1)指向第二个数组, (q + 1)[-1]指的是向前移动一位,指向 3
结果 = 4 - 3 = 1
```

**验证：**

```c
printf("%d\n", *(p + 3) + *(*(q + 1) + 1));  // 4 + 5 = 9
printf("%d\n", *(a[1] - 1) + *(a[0] + 4));   // 3 + 5 = 8
printf("%zu\n", sizeof(a + 1) + sizeof(*a)); // 8 + 12 = 20
printf("%d\n", (p + 2)[1] - (*(q + 1))[-1]); // 4 - 3 = 1
```
