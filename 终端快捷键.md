| 快捷键     | 作用                                           |
| ---------- | ---------------------------------------------- |
| `Ctrl + U` | 删除**光标到行首**（mac 终端默认等于清空整行） |
| `Ctrl + K` | 删除**光标到行尾**                             |
| `Ctrl + W` | 删除光标前面**一个单词**（按空格分割）         |
| `Ctrl + A` | 光标跳到**行首**                               |
| `Ctrl + E` | 光标跳到**行尾**                               |
| `Ctrl + C` | 终止正在运行的程序，放弃当前输入行             |
