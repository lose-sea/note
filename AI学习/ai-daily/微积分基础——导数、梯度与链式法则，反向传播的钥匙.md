# 微积分基础——导数、梯度与链式法则，反向传播的钥匙

**承上**：上一篇《概率与统计》我们知道模型输出的是概率分布，也知道用交叉熵衡量好坏，但「怎么把损失降下去」还没解决。

**本篇**：本篇学导数、梯度与链式法则——反向传播的全部数学基础。

**启下**：下一篇进入阶段 3《监督学习全景》，把这些数学真正用来训练第一个模型。

**学完这一节，你能动手做**：

1. 手推一个两层网络的全部梯度，不再把 backward 当黑盒
2. 用数值梯度做 gradient check，验证自己写的反向传播对不对
3. 从零用 NumPy 训练一个小网络，把 loss 降到接近 0


大模型有几十亿个参数。训练的时候，每个参数都要知道"我该往哪个方向调、调多少"。

回答这两个问题的数学工具就是**导数**和**梯度**。而让这件事在几十亿参数上还能高效算出来的算法，叫**反向传播（Backpropagation）**——它的全部数学基础就是一条**链式法则**。

这一篇我们会：手算导数 → 用代码验证 → 手推一个两层网络的梯度 → 对比"手算梯度"和"数值梯度"完全一致。**做完你会彻底相信反向传播不是魔法。**

## 一、导数：变化的敏感度

### 1.1 直观理解

导数 `f'(x)` 回答一个问题：**x 变动一点点，f(x) 会跟着变多少？**

```python
import numpy as np

def f(x):
    return x ** 2

# 在 x=3 处，x 增加 h，f 增加多少？
x = 3.0
for h in [0.1, 0.01, 0.001, 0.0001]:
    slope = (f(x + h) - f(x)) / h
    print(f"h={h:<8} 近似斜率 = {slope:.6f}")

print("解析解 f'(x)=2x →", 2 * x)   # 6.0
```

h 越小，近似值越接近真实的 6。**数值求导**的定义：

```
f'(x) ≈ (f(x+h) - f(x)) / h
```

### 1.2 为什么模型训练需要导数

训练的目标是**最小化损失 L**。假设 L 依赖参数 w：

- 如果 `dL/dw > 0`：w 增大会让损失变大 → **w 应该减小**
- 如果 `dL/dw < 0`：w 增大会让损失变小 → **w 应该增大**

于是有了深度学习最重要的那一行更新公式：

```python
w = w - learning_rate * dL_dw
```

**减号**意味着"沿着让损失下降的方向走"，**learning_rate** 控制每步走多大。这就是梯度下降。

### 1.3 常用导数（背这几个就够了）

| 函数 | 导数 | 深度学习里在哪用 |
|---|---|---|
| `c`（常数） | 0 | — |
| `x^n` | `n·x^(n-1)` | 多项式、MSE 损失 |
| `e^x` | `e^x` | softmax |
| `ln x` | `1/x` | 交叉熵 |
| `sigmoid` | `σ(1-σ)` | 二分类输出 |
| `tanh` | `1 - tanh²` | RNN 门控 |
| `ReLU` | `x>0 ? 1 : 0` | 几乎所有现代网络 |
| `max(0,x)` | 同上 | — |

**ReLU 的导数是 0 或 1**，简单到极致——这正是它取代 sigmoid 成为主流激活函数的原因之一（sigmoid 在两端导数趋于 0，会导致梯度消失）。

```python
def relu(x):
    return np.maximum(0, x)

def relu_grad(x):
    return (x > 0).astype(float)

x = np.array([-2.0, -0.1, 0.0, 1.5, 3.0])
print("ReLU   :", relu(x))
print("ReLU'  :", relu_grad(x))

def sigmoid(x):
    return 1 / (1 + np.exp(-x))

def sigmoid_grad(x):
    s = sigmoid(x)
    return s * (1 - s)

print("sigmoid':", sigmoid_grad(x).round(3))   # 两端接近 0 → 梯度消失的来源
```

## 二、偏导数与梯度：多变量情形

一个模型有几百万个参数 w₁, w₂, ...，损失 L 对每个参数都有一个偏导数。把它们排成一个向量，就是**梯度**：

```python
def numerical_gradient(f, x, h=1e-6):
    """数值法求梯度：对每个维度单独扰动"""
    x = np.array(x, dtype=float)
    grad = np.zeros_like(x)
    for i in range(x.size):
        old = x[i]
        x[i] = old + h
        fxh1 = f(x)
        x[i] = old - h
        fxh2 = f(x)
        grad[i] = (fxh1 - fxh2) / (2 * h)     # 中心差分，更精确
        x[i] = old
    return grad

# 例：f(w) = w0² + 3*w1²  → 梯度应为 [2w0, 6w1]
def f(w):
    return w[0]**2 + 3 * w[1]**2

w = np.array([2.0, 1.0])
print("数值梯度:", numerical_gradient(f, w))    # ≈ [4. 6.]
print("解析梯度:", np.array([2*w[0], 6*w[1]]))  # [4. 6.]
```

**梯度指向"损失上升最快的方向"，所以我们减去它。**

值得注意：数学上梯度是**列向量**，但工程实现里梯度的形状总是**和参数形状保持一致**——这一点比"行还是列"重要得多。

## 三、链式法则：反向传播的全部秘密

复合函数求导就一条规则：

```
若 y = f(g(x))，则 dy/dx = f'(g(x)) · g'(x)
```

**一句话：把每一步的局部导数连乘起来。**

```python
# 例：L = (2x + 1)²  ，求 dL/dx
# 拆成：u = 2x+1（du/dx = 2），L = u²（dL/du = 2u）
def L_fn(x):
    return (2 * x + 1) ** 2

def chain_rule(x):
    u = 2 * x + 1
    dL_du = 2 * u        # d(u²)/du
    du_dx = 2            # d(2x+1)/dx
    return dL_du * du_dx

x = 3.0
print("链式法则:", chain_rule(x))                            # 2*7*2 = 28
print("数值验证:", (L_fn(x+1e-6) - L_fn(x-1e-6)) / 2e-6)    # ≈ 28
```

完全一致。就这么简单——**反向传播就是在一张大计算图上反复用这一条规则**。

## 四、手推一个两层网络的反向传播

这是本篇的核心。网络结构：

```
输入 x (2维)
  → z1 = W1·x + b1     (3维)
  → a1 = ReLU(z1)
  → z2 = W2·a1 + b2    (1维)
  → L  = (z2 - y)²     (均方误差)
```

参数：W1(3,2), b1(3,), W2(1,3), b2(1,)

### 4.1 前向传播

```python
np.random.seed(0)

x  = np.array([1.0, 2.0])          # 输入
y  = np.array([1.0])               # 真实标签

W1 = np.random.randn(3, 2) * 0.1
b1 = np.zeros(3)
W2 = np.random.randn(1, 3) * 0.1
b2 = np.zeros(1)

# 前向
z1 = W1 @ x + b1          # (3,)
a1 = relu(z1)             # (3,)
z2 = W2 @ a1 + b2         # (1,)
loss = np.sum((z2 - y) ** 2)

print("z1 =", z1.round(4))
print("a1 =", a1.round(4))
print("loss =", round(float(loss), 6))
```

### 4.2 反向传播（手推）

从后往前算：

```python
# ① dL/dz2 = 2(z2 - y)
dz2 = 2 * (z2 - y)                       # (1,)

# ② 由 z2 = W2 @ a1 + b2
dW2 = dz2.reshape(-1, 1) @ a1.reshape(1, -1)   # (1,3) = dL/dz2 · a1^T
db2 = dz2.copy()                                # (1,)
da1 = W2.T @ dz2                                # (3,) = W2^T · dL/dz2

# ③ 由 a1 = ReLU(z1)
dz1 = da1 * relu_grad(z1)                       # (3,)  ← 链式法则乘上局部导数

# ④ 由 z1 = W1 @ x + b1
dW1 = dz1.reshape(-1, 1) @ x.reshape(1, -1)     # (3,2)
db1 = dz1.copy()                                # (3,)

print("dW2 =", dW2.round(5))
print("dW1 =\n", dW1.round(5))
```

**每一步都在做同一件事**：拿上游传回来的梯度，乘上本步骤的局部导数，再传给下游。

### 4.3 用数值梯度验证（关键！）

手推对不对？数值法验一遍：

```python
def forward_all(W1, b1, W2, b2, x, y):
    z1 = W1 @ x + b1
    a1 = np.maximum(0, z1)
    z2 = W2 @ a1 + b2
    return np.sum((z2 - y) ** 2)

def check(name, param, analytic, idx):
    """扰动 param[idx]，比较数值梯度与解析梯度"""
    eps = 1e-6
    args = {"W1": W1.copy(), "b1": b1.copy(), "W2": W2.copy(), "b2": b2.copy()}
    p = args[name].copy()
    p[idx] += eps
    args[name] = p
    f_plus = forward_all(args["W1"], args["b1"], args["W2"], args["b2"], x, y)
    p[idx] -= 2 * eps
    args[name] = p
    f_minus = forward_all(args["W1"], args["b1"], args["W2"], args["b2"], x, y)
    numeric = (f_plus - f_minus) / (2 * eps)
    a = np.asarray(analytic).ravel()[idx]
    print(f"{name}[{idx}]  解析={a: .8f}  数值={numeric: .8f}  误差={abs(a-numeric):.2e}")

check("W2", W2, dW2, 0)
check("W2", W2, dW2, 2)
check("W1", W1, dW1, 0)
check("W1", W1, dW1, 4)
check("b1", b1, db1, 1)
```

运行后你会看到误差在 `1e-9` 量级——**手推的梯度是对的**。

> **梯度检查（gradient checking）** 是写自定义层和自定义损失函数时的救命技巧：数值梯度慢但可靠，解析梯度快但易写错，两者对不上就说明你推错了。**这是每个算法工程师的基本功。**

### 4.4 用梯度真的把 loss 降下去

```python
lr = 0.05
W1_, b1_, W2_, b2_ = W1.copy(), b1.copy(), W2.copy(), b2.copy()

for step in range(200):
    # 前向
    z1 = W1_ @ x + b1_
    a1 = np.maximum(0, z1)
    z2 = W2_ @ a1 + b2_
    loss = np.sum((z2 - y) ** 2)

    # 反向
    dz2 = 2 * (z2 - y)
    dW2 = dz2.reshape(-1, 1) @ a1.reshape(1, -1)
    db2 = dz2.copy()
    da1 = W2_.T @ dz2
    dz1 = da1 * (z1 > 0).astype(float)
    dW1 = dz1.reshape(-1, 1) @ x.reshape(1, -1)
    db1 = dz1.copy()

    # 更新
    W1_ -= lr * dW1
    W2_ -= lr * dW2
    b1_ -= lr * db1
    b2_ -= lr * db2

    if step % 40 == 0 or step == 199:
        print(f"step {step:3d}  loss = {float(loss):.6f}  pred = {float(z2):.4f}")
```

loss 从初始值一路降到接近 0，预测值逼近目标 1.0。**你刚刚从零训练了一个神经网络——没有 PyTorch，只有 NumPy 和链式法则。**

## 五、计算图视角：为什么叫"反向传播"

把上面的计算画成图：

```
x ──┐
    ├─[·W1 + b1]→ z1 ─[ReLU]→ a1 ─[·W2 + b2]→ z2 ─[MSE]→ L
W1 ─┘                                          y ─┘

反向时梯度沿同一条路倒着流回来：
L → dz2 → da1 → dz1 → dW1
```

- **前向**：从左往右算数值，需要保存中间结果（z1、a1）供反向用；
- **反向**：从右往左算梯度，每步用"上游梯度 × 局部导数"。

**为什么必须保存中间激活值？** 因为 `dz1 = da1 * relu'(z1)` 需要 `z1`。这就是训练大模型显存吃紧的根本原因——**不仅要存参数，还要存每一层的激活值**。（梯度检查点技术就是用"重算换显存"。）

PyTorch 的 `loss.backward()` 就是自动做这件事：它在你写前向时悄悄建好了计算图，然后倒着走一遍。

## 六、梯度消失与爆炸（预告深度学习的核心难题）

链式法则是**连乘**。100 层网络就是 100 个数连乘：

```python
print("0.9^100  =", 0.9 ** 100)     # ≈ 2.66e-05  → 梯度消失
print("1.1^100  =", 1.1 ** 100)     # ≈ 13780     → 梯度爆炸
print("0.1^100  =", 0.1 ** 100)     # → 0，彻底传不动
```

- **梯度消失**：早期层梯度趋近 0，学不动（sigmoid 时代的大坑）；
- **梯度爆炸**：梯度指数级变大，参数直接 NaN。

现代解决方案我们后面都会学到：**ReLU 激活**（导数恒为 1，不衰减）、**残差连接 ResNet**（给梯度开一条直通高速路）、**LayerNorm**（稳定数值尺度）、**梯度裁剪**（防爆）。

## 七、常见坑与注意事项

| 坑 | 现象 | 解决 |
|---|---|---|
| 手推梯度写错 | loss 不降或 NaN | 用数值梯度做 gradient check |
| 学习率太大 | loss 震荡甚至发散 | 从 1e-3 开始试，画曲线观察 |
| 学习率太小 | loss 几乎不动 | 提高一个数量级 |
| 忘记清零梯度 | 梯度累加（PyTorch 常见） | 每步 `optimizer.zero_grad()` |
| 用 `+=` 原地改参数 | 破坏计算图 | PyTorch 里用 `torch.no_grad()` |
| ReLU 死神经元 | 梯度恒为 0 不再更新 | 换 LeakyReLU / 降低 lr |
| 数值梯度 h 取值 | h 太大不精确，太小精度损失 | h=1e-6 双精度比较稳 |

## 八、本篇小结

1. **导数 = 敏感度**：`dL/dw` 告诉我们参数该往哪调；更新公式 `w -= lr * dL/dw` 是整个深度学习的引擎。
2. **梯度 = 所有偏导数组成的向量**，形状与参数一致，指向损失上升最快的方向。
3. **链式法则 = 局部导数连乘**，反向传播就是在大计算图上反复应用它，从后往前传梯度。
4. 我们**手推了两层网络的全部梯度，并用数值梯度验证误差 ~1e-9**，然后真的把 loss 训练到了接近 0。
5. **梯度消失/爆炸**源于连乘效应，催生了 ReLU、残差连接、LayerNorm、梯度裁剪等技术。
