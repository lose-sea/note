# 神经网络与反向传播原理

**承上**：阶段 3 我们学会了训练和评估模型，但用的都是「一层」的模型。

**本篇**：本篇进入阶段 4：把线性回归叠很多层、中间插非线性——这就是神经网络。

**启下**：下一篇《PyTorch 张量与 autograd》让框架接管手推梯度的苦力活。

**学完这一节，你能动手做**：

1. 说清为什么没有非线性时，多层网络会退化成一层
2. 从零实现两层网络的前向、反向并做梯度检查
3. 在非线性数据上跑出远超线性模型的准确率，画出弯曲的决策边界


前面所有的铺垫，都是为了这一篇。

你已经知道：线性回归是"一层网络"、Softmax 回归是"一层网络 + Softmax"、梯度下降是训练方法、链式法则是算梯度的工具。那**神经网络**呢？

```
神经网络 = 把很多个"线性回归"叠起来，中间插入非线性函数
```

就这么简单。但正是"叠很多层 + 非线性"这两件事，带来了质变的表达能力——从拟合一条直线，到能理解语言、生成代码。

这一篇我们**完全用 NumPy 从零实现一个两层神经网络**，自己写前向、自己推反向、自己训练，并在非线性数据上跑出 95%+ 的准确率。做完你会真正理解反向传播，而不是只会调 `loss.backward()`。

## 一、神经元：一个小小的计算单元

单个神经元做的事：

```
z = w₁x₁ + w₂x₂ + ... + wₙxₙ + b      ← 线性组合（就是线性回归）
a = f(z)                              ← 激活函数（非线性！）
```

```python
import numpy as np

def neuron(x, w, b, activation="relu"):
    z = np.dot(w, x) + b
    if activation == "relu":
        a = np.maximum(0, z)
    elif activation == "sigmoid":
        a = 1 / (1 + np.exp(-z))
    elif activation == "tanh":
        a = np.tanh(z)
    else:
        a = z                      # 线性（无激活）
    return z, a

x = np.array([0.5, -1.2, 3.0])
w = np.array([0.8, -0.3, 0.1])
b = 0.2

for act in ["relu", "sigmoid", "tanh", "linear"]:
    z, a = neuron(x, w, b, act)
    print(f"{act:>8}: z={z: .4f}  a={a: .4f}")
```

## 二、为什么必须有非线性激活函数？（核心）

**如果不用激活函数，多层网络会退化成一层。**

证明一下：

```
第一层：a₁ = W₁x + b₁
第二层：a₂ = W₂a₁ + b₂ = W₂(W₁x + b₁) + b₂ = (W₂W₁)x + (W₂b₁ + b₂)
                                          ↑ 可以合并成一个矩阵 W' ！
```

**线性 × 线性 = 线性**。无论叠多少层，都等价于一层线性回归，永远只能画直线。

```python
np.random.seed(0)
W1 = np.random.randn(4, 3) * 0.5
W2 = np.random.randn(2, 4) * 0.5
W_merged = W2 @ W1
print("两层合并后形状:", W_merged.shape)   # (2,3) —— 与单层等价！

# 有激活函数就不能合并了
x = np.array([1.0, 2.0, -1.0])
no_act = W2 @ (W1 @ x)                  # = (W2W1) @ x
with_act = W2 @ np.maximum(0, W1 @ x)   # 无法合并
print("无激活:", no_act.round(4))
print("有激活:", with_act.round(4))
print("两者相等?", np.allclose(no_act, with_act - W2 @ np.maximum(0, W1 @ x) + W2 @ (W1 @ x)))
```

有了非线性，网络才能拟合任意复杂形状——这叫**万能近似定理**（Universal Approximation Theorem）：一个足够宽的单隐藏层网络，能以任意精度逼近任意连续函数。

### 常见激活函数对比

```python
import matplotlib.pyplot as plt

z = np.linspace(-4, 4, 200)
acts = {
    "sigmoid": 1 / (1 + np.exp(-z)),
    "tanh": np.tanh(z),
    "ReLU": np.maximum(0, z),
    "LeakyReLU": np.maximum(0.05 * z, z),
    "GELU": 0.5 * z * (1 + np.tanh(np.sqrt(2 / np.pi) * (z + 0.044715 * z**3))),
}

fig, axes = plt.subplots(1, 2, figsize=(13, 4))
for name, a in acts.items():
    axes[0].plot(z, a, lw=2, label=name)
axes[0].set_title("Activation Functions"); axes[0].legend(); axes[0].grid(alpha=0.3)

for name, a in acts.items():
    grad = np.gradient(a, z)
    axes[1].plot(z, grad, lw=2, label=name)
axes[1].set_title("Their Derivatives"); axes[1].legend(); axes[1].grid(alpha=0.3)
plt.tight_layout(); plt.show()
```

| 激活函数 | 输出范围 | 优点 | 缺点 | 用在哪 |
|---|---|---|---|---|
| Sigmoid | (0,1) | 可做概率 | 两端梯度→0（消失）、非零中心 | 二分类输出层 |
| Tanh | (-1,1) | 零中心 | 仍会梯度消失 | RNN 门控 |
| **ReLU** | [0,∞) | 计算极快、正区间梯度恒为1 | 负区间"死神经元" | 隐藏层默认 |
| LeakyReLU | (-∞,∞) | 解决死神经元 | 需调斜率 | ReLU 的备选 |
| **GELU** | (-∞,∞) | 平滑、效果好 | 计算略慢 | **Transformer/大模型标配** |

**注意 GELU 就在图上**——BERT、GPT 用的都是它。平滑的非线性让训练更稳定。

## 三、前向传播：一层层算过去

两层网络结构（本篇主角）：

```
输入 x (2维)
  → z1 = W1x + b1      (隐藏层，64维)
  → a1 = ReLU(z1)
  → z2 = W2a1 + b2     (输出层，2维)
  → p  = Softmax(z2)
  → L  = CrossEntropy(p, y)
```

```python
def softmax(z):
    z = z - np.max(z, axis=-1, keepdims=True)
    e = np.exp(z)
    return e / np.sum(e, axis=-1, keepdims=True)

def forward(x, params):
    """x: (N,2) → 返回 logits 与中间缓存（反向要用）"""
    W1, b1, W2, b2 = params["W1"], params["b1"], params["W2"], params["b2"]
    z1 = x @ W1 + b1          # (N,64)
    a1 = np.maximum(0, z1)    # (N,64) ReLU
    z2 = a1 @ W2 + b2         # (N,2)
    cache = {"x": x, "z1": z1, "a1": a1, "z2": z2}
    return z2, cache
```

**缓存中间值是必须的**——反向算 `ReLU` 的导数时需要 `z1`。

## 四、反向传播：手推每一层

从损失开始往回倒推：

```python
def backward(cache, params, y_onehot):
    N = y_onehot.shape[0]
    x, z1, a1, z2 = cache["x"], cache["z1"], cache["a1"], cache["z2"]

    # ① Softmax + 交叉熵的梯度：(p - y) / N
    p = softmax(z2)
    dz2 = (p - y_onehot) / N                       # (N, 2)

    # ② 输出层参数：z2 = a1 @ W2 + b2
    dW2 = a1.T @ dz2                               # (64,2)
    db2 = np.sum(dz2, axis=0)                      # (2,)
    da1 = dz2 @ params["W2"].T                     # (N,64) 梯度传回隐藏层

    # ③ ReLU：只在 z1 > 0 的位置传递
    dz1 = da1 * (z1 > 0).astype(float)             # (N,64) ← 链式法则

    # ④ 隐藏层参数：z1 = x @ W1 + b1
    dW1 = x.T @ dz1                                # (2,64)
    db1 = np.sum(dz1, axis=0)                      # (64,)

    grads = {"W1": dW1, "b1": db1, "W2": dW2, "b2": db2}
    return grads, p
```

**每一行的形状都对得上**：`dW2` 与 `W2` 同形 `(64,2)`，`dW1` 与 `W1` 同形 `(2,64)`。**形状对齐是检查反向传播是否写对的第一道关卡。**

### 梯度检查（必做）

```python
def compute_loss(params, x, y_onehot):
    z2, _ = forward(x, params)
    p = softmax(z2)
    return -np.sum(y_onehot * np.log(np.clip(p, 1e-12, 1.0))) / len(y_onehot)

def gradient_check(params, x, y_onehot, eps=1e-6):
    z2, cache = forward(x, params)
    grads, _ = backward(cache, params, y_onehot)
    print(f"{'参数':<6}{'解析梯度':>16}{'数值梯度':>16}{'相对误差':>14}")
    for name in ["W1", "b1", "W2", "b2"]:
        idx = np.unravel_index(np.argmax(np.abs(grads[name])), grads[name].shape)
        old = params[name][idx]
        params[name][idx] = old + eps
        f_plus = compute_loss(params, x, y_onehot)
        params[name][idx] = old - eps
        f_minus = compute_loss(params, x, y_onehot)
        params[name][idx] = old
        numeric = (f_plus - f_minus) / (2 * eps)
        analytic = grads[name][idx]
        rel = abs(analytic - numeric) / max(abs(analytic), abs(numeric), 1e-12)
        print(f"{name:<6}{analytic:>16.8f}{numeric:>16.8f}{rel:>14.2e}")

# 初始化并跑检查
np.random.seed(42)
params = {
    "W1": np.random.randn(2, 64) * 0.1,  "b1": np.zeros(64),
    "W2": np.random.randn(64, 2) * 0.1,  "b2": np.zeros(2),
}
X_chk = np.random.randn(8, 2)
Y_chk = np.eye(2)[np.random.randint(0, 2, 8)]
gradient_check(params, X_chk, Y_chk)
```

相对误差应该在 `1e-8` 量级。**如果不是，你的反向传播写错了。**

## 五、完整训练：在非线性数据上跑

用一个"双螺旋/月牙"数据集——线性模型完全无解，必须靠非线性：

```python
from sklearn.datasets import make_moons
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler

np.random.seed(0)
Xm, ym = make_moons(n_samples=600, noise=0.15, random_state=42)
Xm = StandardScaler().fit_transform(Xm)
X_tr, X_te, y_tr, y_te = train_test_split(Xm, ym, test_size=0.25, random_state=42)

def one_hot(y, C):
    out = np.zeros((len(y), C)); out[np.arange(len(y)), y] = 1.0
    return out

Y_tr = one_hot(y_tr, 2)
print("数据形状:", X_tr.shape, " 线性可分?", "否 —— 必须非线性")
```

### 5.1 训练循环

```python
def train(X, Y, hidden=64, lr=0.1, epochs=1000, seed=42):
    rng = np.random.default_rng(seed)
    np.random.seed(seed)
    d, C = X.shape[1], Y.shape[1]
    params = {
        "W1": np.random.randn(d, hidden) * np.sqrt(2.0 / d),   # He 初始化
        "b1": np.zeros(hidden),
        "W2": np.random.randn(hidden, C) * np.sqrt(2.0 / hidden),
        "b2": np.zeros(C),
    }
    history = []

    for ep in range(epochs):
        # --- 全批量前向 ---
        z2, cache = forward(X, params)
        grads, p = backward(cache, params, Y)
        loss = compute_loss(params, X, Y)

        # --- 更新 ---
        for k in params:
            params[k] -= lr * grads[k]

        if ep % 100 == 0 or ep == epochs - 1:
            acc = np.mean(np.argmax(p, axis=1) == np.argmax(Y, axis=1))
            history.append((ep, loss, acc))
            print(f"epoch {ep:4d}  loss={loss:.4f}  acc={acc:.3f}")

    return params, history

params, hist = train(X_tr, Y_tr, hidden=64, lr=0.1, epochs=1000)
```

### 5.2 测试集评估

```python
z2_test, _ = forward(X_te, params)
pred = np.argmax(softmax(z2_test), axis=1)
from sklearn.metrics import accuracy_score
print("测试集准确率:", round(accuracy_score(y_te, pred), 4))
```

通常能到 **95%+**。对比一下线性回归（无隐藏层）在同一数据上只能到 85% 左右：

```python
from sklearn.linear_model import LogisticRegression
lr_model = LogisticRegression(max_iter=1000).fit(X_tr, y_tr)
print("线性模型准确率:", round(accuracy_score(y_te, lr_model.predict(X_te)), 4))
print("神经网络准确率:", round(accuracy_score(y_te, pred), 4))
```

**差距就是"非线性 + 多层"的价值**。

### 5.3 看看决策边界

```python
def plot_boundary(params, X, y, title):
    xx, yy = np.meshgrid(np.linspace(X[:,0].min()-0.5, X[:,0].max()+0.5, 200),
                         np.linspace(X[:,1].min()-0.5, X[:,1].max()+0.5, 200))
    grid = np.c_[xx.ravel(), yy.ravel()]
    _, cache = forward(grid, params)
    Z = np.argmax(softmax(cache["z2"]), axis=1).reshape(xx.shape)
    plt.contourf(xx, yy, Z, alpha=0.3, cmap="coolwarm")
    plt.scatter(X[:, 0], X[:, 1], c=y, cmap="coolwarm", edgecolor="k", s=25)
    plt.title(title); plt.tight_layout(); plt.show()

plot_boundary(params, Xm, ym, "Neural Network Decision Boundary (2-layer)")
```

你会看到一条弯曲的边界完美分开两个月牙——**线性模型永远画不出这样的曲线**。

## 六、权重初始化：一个容易被忽视的生死细节

```python
def compare_init(X, Y, scale, name, epochs=500):
    np.random.seed(0)
    d, C = X.shape[1], Y.shape[1]
    params = {"W1": np.random.randn(d, 64) * scale, "b1": np.zeros(64),
              "W2": np.random.randn(64, C) * scale, "b2": np.zeros(C)}
    for _ in range(epochs):
        z2, cache = forward(X, params)
        grads, p = backward(cache, params, Y)
        for k in params:
            params[k] -= 0.1 * grads[k]
    acc = np.mean(np.argmax(softmax(forward(X, params)[0]), 1) == np.argmax(Y, 1))
    print(f"{name:>20} (scale={scale}):  训练 acc={acc:.3f}")

compare_init(X_tr, Y_tr, 0.0,  "全 0 初始化")     # 对称性灾难
compare_init(X_tr, Y_tr, 0.01, "太小")
compare_init(X_tr, Y_tr, np.sqrt(2/2), "He 初始化")  # 推荐
compare_init(X_tr, Y_tr, 2.0,  "太大")
```

| 初始化 | 后果 |
|---|---|
| **全 0** | 所有神经元梯度相同 → 永远对称 → 网络退化成一个神经元 |
| **太小** | 信号逐层衰减，梯度消失 |
| **太大** | 激活饱和（sigmoid/tanh），梯度趋 0 |
| **He (`√(2/fan_in)`)** | ✅ 配 ReLU 的标准做法 |
| **Xavier (`√(1/fan_in)`)** | 配 tanh/sigmoid |

**PyTorch 已经帮你做好了**（`nn.Linear` 默认用 Kaiming/He 初始化），但自己写网络时必须注意。

## 七、计算图与反向传播的直观理解

```
前向（左→右，算数值，存中间量）
x ──[W1,b1]──→ z1 ──[ReLU]──→ a1 ──[W2,b2]──→ z2 ──[Softmax]──→ p ──→ L
                 ↑               ↑                ↑
              存 z1           存 a1            存 z2

反向（右→左，算梯度，用中间量）
dL ←──────────────────────────────────────────────────────────┘
   → dz2=(p-y)/N → dW2=a1ᵀdz2 → da1=dz2W2ᵀ → dz1=da1·(z1>0) → dW1=xᵀdz1
```

**一句话总结反向传播**：沿计算图倒着走，每步用 "上游梯度 × 本步局部导数" 算出更上游的梯度，顺便把参数梯度算出来。

PyTorch 的 `loss.backward()` 就是在自动做这件事——它在你写 `forward` 时偷偷记录了整张图。

## 八、常见坑与注意事项

| 坑 | 现象 | 解决 |
|---|---|---|
| 反向写错 | loss 不降 | **梯度检查**（数值 vs 解析） |
| 全 0 初始化 | 网络不学习 | 随机初始化 + He/Xavier |
| 忘记存中间值 | 反向算不出 | forward 时缓存 z1/a1 |
| 形状对不上 | 矩阵乘法报错 | 画形状表核对 `(N,d)@(d,h)` |
| 学习率过大 | loss 变 NaN | 降到 1/10 |
| 最后一层加了激活 | 分类效果差 | 输出层保持 logits，Softmax 在损失里做 |
| ReLU 死神经元 | 部分神经元永不激活 | 用 LeakyReLU / 降 lr |

## 九、本篇小结

1. **神经元 = 线性组合 + 非线性激活**；神经网络就是把这玩意儿叠很多层。
2. **没有非线性，多层网络会退化成单层**（线性 × 线性 = 线性），这是激活函数存在的根本理由。
3. **ReLU 是隐藏层默认**（导数 0/1，快），**GELU 是 Transformer 标配**（平滑）；输出层不加激活，直接出 logits。
4. 我们从零实现了**两层神经网络的完整前向 + 反向 + 训练**，用梯度检查验证正确性，在月牙数据上跑到 95%+，远超线性模型。
5. **权重初始化**决定生死：用 He（配 ReLU）或 Xavier（配 tanh），绝不能全 0。
