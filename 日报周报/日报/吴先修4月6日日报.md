## 今日算法题

### 题目1: [56. 合并区间](https://leetcode.cn/problems/merge-intervals/) 

![image-20260406211149593](/Users/lose_sea/Library/Application Support/typora-user-images/image-20260406211149593.png)

```objc
class Solution {
public: 
    vector<vector<int>> merge(vector<vector<int>>& intervals) {  
        sort(intervals.begin(), intervals.end()); 
        vector<vector<int>> result; 
        for (vector<int> p : intervals) {
            if (!result.empty() && p[0] <= result.back()[1]) {
                result.back()[1] = max(result.back()[1], p[1]); 
            } else {
                result.push_back(p); 
            }
        } 
        return result; 
    }
};
```
