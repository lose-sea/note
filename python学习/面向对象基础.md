## 面向过程编程 

#### 核心思想: 

把一个需求分解成一系列要执行的步骤, 然后按照步骤执行这些任务 (关注的是流程, 步骤) 

### 适用场景: 面向过程编程非常直接, 适合简单, 线性的任务

## 面向对象编程 

对象可以理解为现实中具体的人/物在程序中的数字化身 (万物皆对象) 

它把一个人/物的属性和方法打包到一起, 是面向对象编程的基本单元

# 面向对象编程 - 类和对象

类: 描述的是一组具有相同属性(特征) 和 方法 (功能/行为) 的模版

对象; 对象是类的实例, 是基于类创建出来的(实例对象) 

## 类的定义

语法:  

```python
class 类名: 
    pass 

# 创建对象
对象名 = 类名() 
对象名.属性名1 = 属性值 
对象名.属性名2 = 属性值
```

**说明: 类的命名规范: 遵循大驼峰命名法, 每个单词的首字母都是大写, 单词之间没有分隔符, 例如: `UserInfo, UserAccount`**

**说明: `__dict__`是python中用户自定义类实例的一个特殊属性, 用于以字典的形式存储对象的属性**  

`print(对象名.__dict__)` 以字典的形式输出属性

```python
class Car :
    pass

c1 = Car()
c1.color = "red"
c1.brand = "BMW"
c1.pirce = 5777

print(c1) # <__main__.Car object at 0x10186dfd0>
print(c1.__dict__) # {'color': 'red', 'brand': 'BMW', 'pirce': 5777}
```

## 方法

 定义在类的外面的称为函数, 定义在类中的函数称为方法

## 魔法方法

魔法方法是指python中提供的以双下划线开头和结尾的方法, 用于定义类的特殊行为, 例如: `__init__` 

**魔法方法不需要我们手动调用, python会在合适的时机自动调用**

| 魔法方法                               | 描述                                                     |
| -------------------------------------- | -------------------------------------------------------- |
| `__init__`                             | 初始化方法                                               |
| `__str__`                              | 字符串表示的方法                                         |
| `__eq__`                               | 比较两个对象是否相等（equal）                            |
| `__lt__`、`__le__`、`__gt__`、`__ge__` | 支持比较两个对象的大小（小于、小于等于、大于、大于等于） |

默认自定义的对象之间不可以进行大小比较

```python
class Car:
    def __init__(self, name, price):
        self.name = name
        self.price = price
    def running(self):
        print(f"{self.name} is running")
    def __str__(self):
        return (f"{self.name} 的价格为 {self.price}")
    def __eq__(self, other): 
        return self.name == other.name and self.price == other.price 
    def __lt__(self, other): 
        return self.price < other.price
```

## 属性

属性分为: 

+ 实例属性: 实力属性属于每个具体对象的属性, 每个对象都是独立的 (每个对象特有的数据) ]
+ 类属性: 类属性是属于类本身的属性, 所有实例共享的,  (所有对象共享的数据或配置)
