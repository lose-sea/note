# 数据分析

数据分析: 从一堆看似杂乱的数据中，通过数据清洗、分析、可视化等手段，找出有价值的信息和结论，从而帮我们解决实际的问题（如：用户订单数据的分析、电影榜单数据分析、学校学生成绩分析等）。



## Jupyter NoteBook 

Jupyter Notebook 是一个基于 Web 网页的、交互式的编程笔记本，让你可以把代码、运行结果、图表和笔记全部都放在一个文件里（在数据分析、机器学习、教学和科研等领域的数据实验室）。



## Pandas 介绍

Pandas是一个功能强大的结构化数据分析工具, 底层是基于Numpy构建的, 无论是在数据分析领域, 还是在大数据开发场景中都有显著优势.
