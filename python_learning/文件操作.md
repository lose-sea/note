计算机只认识 0 和 1, 所以需要将内容翻译为 0 和 1 才能保存在计算机中, 同时也需要编码, 将计算机中保存的 0 和 1, 反向翻译回可以识别的内容

## 什么是编码

编码就是一种规则集合, 记录了内容和二进制间相互进行转换的逻辑,编码有许多中, 我们最常用的是 UTF-8 编码

## 文件的操作步骤

我们平时对文件基本操作, 大概可以分为三个步骤

1. 打开文件
2. 读写文件
3. 关闭文件

### open() 打开文件

在python中, 使用 open 函数, 可以打开一个已经存在的文件, 或者创建一个新文件

```python
open(name, mode, encoding)
```

> name: 要打开的目标文件名的字符串, 可以包含文件所在的具体路径) 
>
> mode: 设置打开文件的模式(访问模式): 只读, 写入, 追加等
>
> encoding: 编码格式 

例如: 

```python
f = open('python.txt', 'w', encoding = "UTF-8")
```

此时的 ‘f’ 是 open 函数的文件对象, 对象是 python 中一种特殊的数据类型, 拥有属性和方法, 可以使用对象, 属性或对象, 方法对其进行访问

```python
f = open('python.txt', 'r', encoding = "UTF-8")
print(type(f))	 # <class '_io.TextIOWrapper'>
```





#### mode常用的三中基础访问模式

| 模式 | 描述                                                         |
| ---- | ------------------------------------------------------------ |
| r    | 以只读方式打开文件。文件的指针将会放在文件的开头。这是默认模式。 |
| w    | 打开一个文件只用于写入。如果该文件已存在则打开文件，并从开头开始编辑，原有内容会被删除。如果该文件不存在，创建新文件。 |
| a    | 打开一个文件用于追加。如果该文件已存在，新的内容将会被写入到已有内容之后。如果该文件不存在，创建新文件进行写入。 |

## 读文件

### read() 方法:

```python
文件对象.read(num)
```

num表示要从文件中读取的数据的长度(单位是字节), 如果没有传入 num, ,那么就表示读取文件中所有的数据 

```python
f = open("python.txt", 'r', encoding='UTF-8')
# 读取10个字节
print(f"读取10个字符的内容: {f.read(10)}")
```



### readlines() 方法

readlines 可以按照行的方式把整个文件中的内容进行一次性读取, 并且返回的是一个列表, 其中每一行的数据为一个元素 



```python
f = open("python.txt", 'r', encoding='UTF-8')
content = f.readlines()

print(type(content)) # <class 'list'>

print(content) # ['hello xinyan\n', 'hello world\n', 'hello\n']

f.close()
```

### readline() 方法

一次读取一行

```python
f = open("python.txt", 'r', encoding='UTF-8')
content = f.readline()
print(content)
content = f.readline()
print(content)
content = f.readline()
print(content)
# 
f.close()

输出: 
hello xinyan

hello world

hello

```
