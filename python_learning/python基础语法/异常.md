# 异常

## 什么是异常

当检测到一个错误的时候, python解释器就无法继续执行了, 反而出现了一些错误的提示, 这就是所谓的异常, 也就是我们常说的bug

## 为什么要捕获异常

当我们的程序遇到了bug, 那么接下来有两种情况

1. ① 整个程序因为一个bug停止运行
2. ② 对bug进行提示, 整个程序继续运行

在之前的学习中, 我们所有的程序遇到bug 就会出现整个程序停止运行的情况, 也就是整个程序直接奔溃

但是在真实的工作中, 我们不能因为一个小的bug就让整个程序全部奔溃, 也就是我们希望的达到 ② 的这种情况, 那这里我们就需要使用到捕获异常 

**捕获异常的作用在于: 提前假设某处会出现异常, 做好提前准备, 当整的出现异常的时候, 可以有后续手段**
