## Python 元组（Tuple）所有方法汇总

元组是**不可变序列**，一旦创建就不能修改。因此元组的方法非常少，主要集中在**查找和统计**上。

------

## 一、元组方法速览

元组只有 **2 个内置方法**：

| 方法                   | 说明                          | 示例               |
| :--------------------- | :---------------------------- | :----------------- |
| `count(x)`             | 统计元素 x 在元组中出现的次数 | `t.count(2)` → `3` |
| `index(x, start, end)` | 查找元素 x 第一次出现的索引   | `t.index(2)` → `1` |

没错，就这两个！😅

------

## 二、方法详解

### 1. `count(x)` - 计数

python

```
# 基本用法
t = (1, 2, 3, 2, 4, 2, 5)
print(t.count(2))  # 3
print(t.count(9))  # 0 (不存在返回0)

# 统计字符串
t = ('a', 'b', 'a', 'c', 'a')
print(t.count('a'))  # 3

# 统计混合类型
t = (1, 'hello', 2, 'hello', 3)
print(t.count('hello'))  # 2
```



### 2. `index(x, start, end)` - 查找索引

python

```
# 基本用法
t = (1, 2, 3, 2, 4, 2, 5)
print(t.index(2))        # 1 (第一次出现的位置)
print(t.index(2, 2))     # 3 (从索引2开始找)
print(t.index(2, 3, 6))  # 5 (在索引3到6之间找)

# 元素不存在会报错
# print(t.index(9))      # ValueError: tuple.index(x): x not in tuple

# 查找字符串
t = ('a', 'b', 'c', 'd')
print(t.index('c'))      # 2
```

## 三、元组的其他操作（虽然不是方法，但常用）

### 1. 获取长度 - `len()`

python

```
t = (1, 2, 3, 4, 5)
print(len(t))  # 5
```



### 2. 成员检查 - `in` / `not in`

python

```
t = (1, 2, 3, 4, 5)
print(3 in t)      # True
print(6 in t)      # False
print(6 not in t)  # True
```



### 3. 最大值/最小值 - `max()` / `min()`

python

```
t = (3, 1, 4, 1, 5, 9)
print(max(t))  # 9
print(min(t))  # 1

# 字符串元组（按字母顺序）
t = ('apple', 'banana', 'cherry')
print(max(t))  # 'cherry'
print(min(t))  # 'apple'
```



### 4. 求和 - `sum()`

python

```
t = (1, 2, 3, 4, 5)
print(sum(t))       # 15
print(sum(t, 10))   # 25 (从10开始加)
```



### 5. 排序 - `sorted()`

python

```
t = (3, 1, 4, 1, 5)
print(sorted(t))        # [1, 1, 3, 4, 5] (返回列表)
print(sorted(t, reverse=True))  # [5, 4, 3, 1, 1]

# 元组排序后转为元组
sorted_t = tuple(sorted(t))
print(sorted_t)         # (1, 1, 3, 4, 5)
```



### 6. 解包（Unpacking）

python

```
# 元组解包是 Python 的特色
t = (1, 2, 3)
a, b, c = t
print(a, b, c)  # 1 2 3

# 使用 * 收集剩余元素
t = (1, 2, 3, 4, 5)
a, *middle, b = t
print(a)        # 1
print(middle)   # [2, 3, 4]
print(b)        # 5
```



### 7. 拼接 - `+` 和 `*`

python

```
# 拼接
t1 = (1, 2, 3)
t2 = (4, 5, 6)
print(t1 + t2)  # (1, 2, 3, 4, 5, 6)

# 重复
print(t1 * 3)   # (1, 2, 3, 1, 2, 3, 1, 2, 3)
```



### 8. 切片

python

```
t = (0, 1, 2, 3, 4, 5)
print(t[1:4])    # (1, 2, 3)
print(t[::2])    # (0, 2, 4)
print(t[::-1])   # (5, 4, 3, 2, 1, 0) (反转)
```
