# 装饰器

装饰器本质上是一种闭包, 其功能就是在不**破坏目标函数原有的代码和功能**的前提下, **为目标函数增加新功能**. 

函数拥有一下特点: 

1. 函数可以作为参数进行传递
2. 函数可以作为返回值进行返回
3. 函数名称可以当成变量一样进行赋值操作



现在有一个 sleep 函数

```python
def sleep(): 
    import random
    import time 
    print("sleeping")
    time.sleep(random.randint(1, 5))
```

现在希望给 sleep 函数增加一个新功能: 

+ 在调用 sleep 前输出: `I will sleep` 
+ 在调用 sleep 后输出: `I wake`

有下面的代码: 

```python
print("I will sleep")
sleep() 
print("I wake")
```

但是这样的方式非常的不优雅,那有没有其他方式呢, 有的, 可以使用 装饰器来实现



### 装饰器的一般写法 (闭包写法)



```python
def sleep():
    import random
    import time
    print("sleeping")
    time.sleep(random.randint(1, 5))

def outer(func):
    def inner():
        print("I will sleep")
        func()
        print("I wake")
    return inner

fn = outer(sleep)
fn()
```



### 装饰器的语法糖写法



```python
def outer(func):
    def inner():
        print("I will sleep")
        func()
        print("I wake")
    return inner

@outer
def sleep():
    import random
    import time
    print("sleeping ...")
    time.sleep(random.randint(1, 5))

sleep() 
```

使用@outer, 定义在目标函数之上

这种写法与装饰器的一般写法的调用方式以一样的, 这里调用 `sleep()` , 本质上调用的还是 `inner()` 



## 装饰器带参数

先给出无参形式的代码

```python
def outer(func):
    def inner():
        print("start")
        func()
        print("end")
    return inner


@outer
def sleep(time):
    print("sleeping")

sleep()
```



现在要给上述的`sleep`函数添加一个参数 

```python
def sleep(time):
    print(f"sleeping, time: {time}")
```

那么再按照原来的方式调用就会报错

```python
def outer(func):
    def inner():
        print("start")
        func()
        print("end")
    return inner

@outer
def sleep(time):
    print(f"sleeping, time: {time}")

sleep(45)
```



上述代码中`@outer` 等价于 `sleep = outer(sleep)`, 实际上就是调用 `inner() `

当`@outer`装饰`sleep`函数时，`outer(sleep)`返回的是`inner`函数，而`inner`没有参数，导致调用`sleep()`时无法传递`time`参数。

解决方法: 在`inner`函数中添加`*args, **kwargs`来接收任意参数，并传递给`func`

```python
def outer(func):
    def inner(*args, **kwargs):
        print("start")
        func(*args, **kwargs)
        print("end")
    return inner


@outer
def sleep(time):
    print(f"sleeping, time: {time}")


sleep(32)
```

输出: 

```python
start
sleeping, time: 32
end
```

## 装饰器之原函数带返回值

下面要演示原函数带返回值

下面函数返回值并且要打印返回值

```python
def sleep(time):
    print(f"sleeping, time: {time}")
    return "wake"

print(sleep(1)) # wake
```

那么现在要给这个函数添加一个装饰器 

只需要在装饰器内部用一个变量接收返回值并且内部的`inner()`返回这个返回值即可

```python
def outer(func):
    def inner(*args, **kwargs):
        print("start")
        ret = func(*args, **kwargs)
        print("end") 
        return ret
    return inner


@outer
def sleep(time):
    print(f"sleeping, time: {time}")
    return "wake"

print(sleep(1))
```



### 一个函数可以被多个装饰器装饰

```python
def wrapper1(func):
    def inner(*args,**kwargs):
        print("in wrapper1")
        func(*args,**kwargs)
        print("out wrapper1")
    return inner

def wrapper2(func):
    def inner(*args,**kwargs):
        print("in wrapper2")
        func(*args,**kwargs)
        print("out wrapper2")
    return inner


@wrapper1
@wrapper2
def target():
    print("in target")


target() 
```



打印: 

```python
in wrapper1
in wrapper2
in target
out wrapper2
out wrapper1
```



 **装饰器的执行顺序是从下往上**



```python
@wrapper1
@wrapper2
def target():
    print("in target")
```



**等价于**：

```
target = wrapper1(wrapper2(target))
```

**执行步骤**：

1. **装饰阶段**（定义时）：

   - `@wrapper2` 先执行：`target = wrapper2(target)` → `target` 变成 `wrapper2` 的 `inner`
   - `@wrapper1` 后执行：`target = wrapper1(已装饰的target)` → `target` 变成 `wrapper1` 的 `inner`

2. **调用阶段**（`target()` 时）：

   ```
   wrapper1.inner() 开始
   ├── 打印 "in wrapper1"
   ├── 调用 func() → 这个 func 是 wrapper2.inner()
   │   ├── 打印 "in wrapper2"
   │   ├── 调用 func() → 这个 func 是原始的 target()
   │   │   └── 打印 "in target"
   │   └── 打印 "out wrapper2"
   └── 打印 "out wrapper1"
   ```



## 通用装饰器的写法:

```python
def wrapper(fn):
    def wrapper(*args, **kwargs):
        # 目标函数执行之前 ...
        ret = fn(*args, **kwargs)
        # 目标函数执行之后 ...
        return ret
    return wrapper # 不加()


@wrapper
def target(*args, **kwargs):
    pass
```

这里添加装饰器之后再调用目标函数 `target()`, 实际上就是调用 `inner() `
