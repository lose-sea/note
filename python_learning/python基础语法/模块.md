# 模块(module))

python模块(module): 一个.py文件就是一个模块, 模块是python 程序的基本组织单位, 在模块中可以定义变量.函数, 类 ,以及可执行的代码

## 模块的作用=

python 中有很多各种不同的模块，每一个模块都可以帮助我们快速的实现一些功能，比如实现和时间相关的功能就可以使用 time 模块

我们可以认为一个模块就是一个工具包，每一个工具包中都有各种不同的工具供我们使用进而实现各种不同的功能

## 模块的导入



+ 在使用模块中提供的功能之前，必须得先导入，再使用。
+ 导入模块的具体语法如下：

| 导入形式                        | 代码样例                           | 调用方式      | 调用方式示例            |
| ------------------------------- | ---------------------------------- | ------------- | ----------------------- |
| import 模块名                   | import random, os                  | 模块名.功能名 | random.randint(10, 100) |
| import 模块名 as 别名           | import random as rd                | 别名.功能名   | rd.randint(10, 100)     |
| from 模块名 import 功能名       | from random import randint,choice  | 功能名        | randint(10, 100)        |
| from 模块名 import 功能名 as 名 | from random import randint as rint | 别名          | rint(10, 100)           |
| from 模块名 import *            | from random import *               | 功能名        | randint(10, 100)        |

## 自定义模块

当开发一些复杂的项目, 为了让项目结构更加清晰, 更便于项目的维护管理以及代码的复用, 可能把一个项目拆分为若干个模块

> 每个python文件都可以作为一个模块, 模块的名称就是文件的名字(建议使用python标识符定义,规范命名) 

**常量的名称是大写**



**__name\_\_是python中的内置变量, 表示当前模块的名字**

```python
import my_fun

print(my_fun.log_separator1())
print(my_fun.log_separator2())
print(my_fun.log_separator3())
print(my_fun.log_separator4())

print(__name__) 

if __name__ == "__main__": 	# 判断
    my_fun.log_separator1()
```

**__all\_\_是一个模块级别的特殊变量, 用于指定 from 模块名 import \*  时会导入哪些功能**

```python
my_fun.py 

__all__ = ["log_separator1", "log_separator2"]
```

## 软件包(package)

包 : 本质就是一个文件夹, 该文件夹中可以包含若干python 模块(,python文件), 文件夹下还包含了`__init__.py`

作用: 模块文件较多时,用来管理多个模块( 包的本质也是一个模块) 

| 导入形式                        | 代码样例                                | 调用方式             | 调用示例                      |
| ------------------------------- | --------------------------------------- | -------------------- | ----------------------------- |
| import 包名.模块名              | import utils.my_fun                     | 包名。模块名。功能名 | utils.my_fun.log_separator1() |
| from 包名 import 模块名         | from utils import my_fun                | 模块名。功能名       | my_fun.log_separator1()       |
| from 包名 import *              | from utils import *                     | 模块名。功能名       | my_fun.log_separator1()       |
| from 包名。模块名 import 功能名 | from utils.my_fun import log_separator1 | 功能名               | log_separator1()              |
| from 包名.模块名 import *       | from utils.my_fun import *              | 功能名               | log_separator1()              |

**在文件夹下面添加`__init__.py`才能成为软件包**

**注意: 要通过`from 名字 import * ` 导入全部模块的时候, 需要在`__init__.py`中添加`__add__ = []`控制允许导入的模块列表**
