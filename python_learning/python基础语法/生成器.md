# 生成器

生成器的本质是迭代器

创建生成器的两种方案: 

+ 生成器函数
+ 生成器表达式

## 生成器函数 

生成器函数中有一个关键字 yield 

普通函数

```python
def func():
    print(9999)
    return 123

ret = func() # 9999
print(ret) # 123
```



把普通函数中的`return`替换为`yield`就变成了生成器函数 

```python
def func():
    print(9999)
    yield 123

ret = func()
print(ret) # <generator object func at 0x000001DFFBDACAC0>
```

生成器函数执行的时候, 得到的是生成器, 并不会执行函数 

因为生成器的本质是迭代器, 所以我们可以像使用迭代器一样去使用它

```python
def func():
    print(9999)
    yield 123

ret = func()
print(ret.__next__())
```

打印: 

```python
9999
123 
```

上面这段代码中 `9999` 是`ret.__next__()`打印的, 123是通过print() 打印的函数返回值 

yield 只有执行到next的时候才会返回数据



## yield 关键字

只要函数中出现了yield, 它就是一个生成器函数 

作用: 

1. 可以返回数据 

2. 可以分段执行函数中的内容 , 通过`__next__()` 可以执行下一个yield的位置 

   ```python
   def func():
       print(1)
       yield 666
       print(2)
       yield 666
       print(3)
       yield 666
   
   ret = func()
   ret.__next__() # 1
   ret.__next__() # 2
   ret.__next__() # 3
   ```

3. 可以节省内存



# 生成器推导式 

推导式: 

+ 简化代码 
+ 语法: 
  - 列表推导式  `[数据 for循环 if 判断]`
  - 集合推导式  `{数据 for循环 if 判断}`
  - 字典推导式 `{k: v for循环 if 判断}`



注意: 没有元组推导式 



创建一个列表, 包含数字1到9所有数据  

方式一: 循环添加

```python
lst = []
for i in range(10):
    lst.append(i)
print(lst)
```



方式二: 列表推导式

```python
lst = [x for x in range(10)]
```



# 生成器表达式



```python
gen = (i**2 for i in range(10))
print(gen) # <generator object <genexpr> at 0x00000169DC4B8FB0>
```





```python

gen = (i**2 for i in range(10))
print(gen) # <generator object <genexpr> at 0x00000169DC4B8FB0>
print(gen.__next__()) # 0
print(gen.__next__()) # 1
print(gen.__next__()) # 4
print(gen.__next__()) # 9
```

全部打印:  

方法一: 

```python
gen = (i**2 for i in range(10)) 

for item in gen:
    print(item) 
```

方法二: 

```python
gen = (i**2 for i in range(10))
lst = list(gen)
print(lst) # [0, 1, 4, 9, 16, 25, 36, 49, 64, 81]
```

如上所示代码,  list()中包含了循环迭代 , 例如: 

```python
s = list("hello")
print(s) # ['h', 'e', 'l', 'l', 'o']
```

list() 将括号内的字符串循环迭代, 最终将元素一个个放入列表中 

所以 list() 中一定有for循环, for循环中一定有 next()
