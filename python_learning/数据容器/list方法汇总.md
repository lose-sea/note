## Python 列表（List）所有方法详解

Python 列表是**可变序列**，支持增删改查等各种操作。按功能分类整理如下：

------

## 一、添加元素（4个方法）

| 方法               | 说明                                 | 示例                                |
| :----------------- | :----------------------------------- | :---------------------------------- |
| `append(x)`        | 在列表**末尾**添加一个元素           | `lst.append(5)` → `[1,2,3,5]`       |
| `extend(iterable)` | 将**可迭代对象**的所有元素追加到末尾 | `lst.extend([4,5])` → `[1,2,3,4,5]` |
| `insert(i, x)`     | 在**索引 i** 处插入元素 x            | `lst.insert(1, 9)` → `[1,9,2,3]`    |
| `+` 运算符         | 合并两个列表（**生成新列表**）       | `[1,2] + [3,4]` → `[1,2,3,4]`       |

python

```
# 示例
lst = [1, 2, 3]
lst.append(4)           # [1, 2, 3, 4]
lst.extend([5, 6])      # [1, 2, 3, 4, 5, 6]
lst.insert(2, 99)       # [1, 2, 99, 3, 4, 5, 6]
```



------

## 二、删除元素（4个方法）



| 方法        | 说明                                            | 示例                                    |
| :---------- | :---------------------------------------------- | :-------------------------------------- |
| `remove(x)` | 删除**第一个**值为 x 的元素（不存在则报错）     | `lst.remove(3)` → `[1,2,4]`             |
| `pop(i)`    | 删除**索引 i** 处元素并返回（默认删除最后一个） | `lst.pop()` → 返回5，列表变为 `[1,2,3]` |
| `clear()`   | 清空列表所有元素                                | `lst.clear()` → `[]`                    |
| `del` 语句  | 删除指定索引或切片（Python语法，非方法）        | `del lst[1:3]` → 删除索引1到2           |



```
# 示例
lst = [1, 2, 3, 2, 4]
lst.remove(2)           # [1, 3, 2, 4]  # 只删除第一个2
last = lst.pop()        # 返回4，列表变为 [1, 3, 2]
lst.pop(1)              # 返回3，列表变为 [1, 2]
lst.clear()             # []
```



------

## 三、查找与访问（5个方法）



| 方法                   | 说明                                      | 示例                 |
| :--------------------- | :---------------------------------------- | :------------------- |
| `index(x, start, end)` | 返回第一个值为 x 的**索引**（找不到报错） | `lst.index(3)` → `2` |
| `count(x)`             | 统计值为 x 的元素**出现次数**             | `lst.count(2)` → `3` |
| `in` 运算符            | 判断元素是否存在（返回布尔值）            | `3 in lst` → `True`  |
| `len()`                | 获取列表长度（内置函数）                  | `len(lst)` → `5`     |
| `max()/min()`          | 获取最大/最小值（内置函数）               | `max(lst)` → `9`     |

```
# 示例
lst = [1, 2, 3, 2, 4, 2]
lst.index(2)            # 返回 1
lst.index(2, 2)         # 从索引2开始找，返回 3
lst.count(2)            # 返回 3
5 in lst                # False
len(lst)                # 6
```

## 四、排序与反转（3个方法）

| 方法                            | 说明                                         | 示例                            |
| :------------------------------ | :------------------------------------------- | :------------------------------ |
| `sort(key=None, reverse=False)` | **就地排序**（修改原列表）                   | `lst.sort()` → `[1,2,3,5]`      |
| `reverse()`                     | **就地反转**列表顺序                         | `lst.reverse()` → `[5,4,3,2,1]` |
| `sorted()`                      | 返回**新排序列表**（内置函数，不修改原列表） | `sorted(lst, reverse=True)`     |

```
# 示例
lst = [3, 1, 4, 2]
lst.sort()              # [1, 2, 3, 4]
lst.sort(reverse=True)  # [4, 3, 2, 1]
lst.reverse()           # [1, 2, 3, 4]

# 自定义排序：按字符串长度排序
words = ['apple', 'pie', 'banana']
words.sort(key=len)     # ['pie', 'apple', 'banana']

# sorted 不修改原列表
new_lst = sorted(lst)   # 生成新列表
```

## 五、复制列表（3种方式）

| 方法     | 说明                   | 示例               |
| :------- | :--------------------- | :----------------- |
| `copy()` | 返回列表的**浅拷贝**   | `new = lst.copy()` |
| `切片`   | 使用 `[:]` 创建浅拷贝  | `new = lst[:]`     |
| `list()` | 使用构造函数创建浅拷贝 | `new = list(lst)`  |



```
# 示例
lst = [1, 2, 3]
copy1 = lst.copy()      # [1, 2, 3]
copy2 = lst[:]          # [1, 2, 3]
copy3 = list(lst)       # [1, 2, 3]

# 注意：浅拷贝对于嵌套列表只复制引用
lst = [[1, 2], [3, 4]]
copy = lst.copy()
copy[0][0] = 99
print(lst)              # [[99, 2], [3, 4]]  # 原列表被修改！
```

## 七、列表常用操作速查表



```
# 创建列表
lst = []                        # 空列表
lst = [1, 2, 3]                 # 直接初始化
lst = list(range(5))            # [0, 1, 2, 3, 4]
lst = [x*2 for x in range(5)]   # 列表推导式 [0, 2, 4, 6, 8]

# 访问元素
first = lst[0]                  # 第一个元素
last = lst[-1]                  # 最后一个元素
sub = lst[1:4]                  # 切片 [索引1, 2, 3]
sub2 = lst[::2]                 # 步长为2 [0, 2, 4]

# 修改元素
lst[0] = 100                    # 修改指定位置
lst[1:3] = [8, 9]               # 切片赋值

# 遍历列表
for item in lst:
    print(item)

for i, item in enumerate(lst):
    print(i, item)              # 同时获取索引和值

# 列表拼接
lst = [1, 2] + [3, 4]           # [1, 2, 3, 4]
lst = [1, 2] * 3                # [1, 2, 1, 2, 1, 2]
```

## 八、完整方法总结（11个内置方法）

```
# Python 列表的所有内置方法（按字母排序）
lst.append(x)           # 末尾添加
```

## 九、注意事项与最佳实践

### 1. 可变性（重要）

```
#  错误：列表是可变对象，修改会互相影响
a = [1, 2, 3]
b = a
b.append(4)
print(a)  # [1, 2, 3, 4]  # a 也被修改了！

#  正确：使用 copy() 创建副本
a = [1, 2, 3]
b = a.copy()
b.append(4)
print(a)  # [1, 2, 3]
print(b)  # [1, 2, 3, 4]
```



### 2. 性能对比

```
# 添加元素性能比较（从快到慢）
lst.append(1)        #  O(1)
lst.insert(0, 1)     #  O(n) 需要移动所有元素
lst = lst + [1]      #  O(n) 创建新列表
lst += [1]           #  O(1) 相当于 extend
```



### 3. 删除元素注意事项



```python
#  遍历时删除会出问题
list = [1, 2, 3, 2, 2, 4, 5, 6, 7, 8, 9, 10]
for num in list:
    if num % 2 == 0:
        list.remove(num)

print(list) # [1, 3, 2, 5, 7, 9]

#  使用列表推导式创建新列表
lst = [i for i in lst if i % 2 != 0]  # [1, 3]

#  或从后往前遍历删除
for i in range(len(lst)-1, -1, -1):
    if lst[i] % 2 == 0:
        del lst[i]
```



### 4. 判断空列表

```
# 推荐
if not lst:
    print("列表为空")

# 不推荐
if len(lst) == 0:
    print("列表为空")
```
