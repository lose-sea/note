| **第 3-4 周** | Python 进阶（够用就行）     | ① **闭包**：花 2 小时搞懂“函数内部定义函数并返回”即可，不做复杂练习。 ② **装饰器**：花 1 天搞懂 `@` 语法，能看懂 `@app.route()` 这种写法就够了。 ③ **重点**：学会 `try/except` 异常处理、`with` 上下文管理器（读写文件必用）。 |

| **第 7-8 周** | 第一个完整数据处理项目      | ① 找一份**电商订单 CSV 数据**（网上很多）。 ② 用 Pandas 完成：数据清洗 → 按月统计销售额 → 找出 TOP 10 热销商品 → 输出一份汇总报告（存为新的 CSV）。 ③ 把代码整理成 `.py` 文件，学会用 `if __name__ == "__main__"` 组织代码。 |

### 🔹 第二阶段：大模型入门与 API 调用（第 9-14 周）

**目标**：能调通大模型 API，写出第一个 AI 对话程序

| 周次            | 学习内容                    | 具体行动（按天拆解）                                         |
| :-------------- | :-------------------------- | :----------------------------------------------------------- |
| **第 9-10 周**  | 大模型通识 + API 调用       | ① 看一遍 **《大模型白话指南》**（网上找，不用看太深，有个概念就行）。 ② 注册 **智谱AI（GLM）** 或 **讯飞星火**（国内免费额度多）。 ③ 用 `requests` 库写一个脚本：输入用户问题，返回大模型回答。 ④ 升级脚本：实现**多轮对话记忆**（用列表存历史消息）。 |
| **第 11-12 周** | Prompt Engineering 入门     | ① 学习 **Few-shot**（给几个例子再提问）和 **Chain-of-Thought**（让模型分步思考）。 ② 作业：用 Prompt 让大模型做**情感分类**（给一段影评，输出“正面/负面”）。 ③ 作业：用 Prompt 让大模型**从一段文字中提取结构化信息**（如：姓名、日期、金额）。 |

### 🔹 第三阶段：RAG 检索增强生成（第 15-24 周）

**目标**：搭建企业级知识库问答系统，这是字节面试必问

| 周次            | 学习内容                 | 具体行动（按天拆解）                                         |
| :-------------- | :----------------------- | :----------------------------------------------------------- |
| **第 15-16 周** | 向量化与相似度搜索       | ① 理解什么是 **Embedding**（文本 → 向量）。 ② 学习 **ChromaDB** 或 **FAISS**（向量数据库，安装并跑通官方示例）。 ③ 作业：把 10 段不同的文本转成向量存入数据库，然后搜索“最相似”的文本。 |
| **第 17-19 周** | RAG 完整流程             | ① 学习 RAG 标准流程：文档加载 → 文本切块 → 向量化存储 → 检索 Top-K → 交给大模型生成。 ② 作业：下载一份 **PDF 文档**（比如公司财报），用 `pypdf` 或 `langchain.document_loaders` 读取。 ③ 完成完整 RAG 代码：用户提问 → 检索相关片段 → 大模型生成回答。 ④ **重点**：学会调整 **chunk_size**（切块大小）和 **top_k**（检索数量），观察回答质量变化。 |
| **第 20-22 周** | RAG 进阶优化             | ① 学习 **混合检索**（Hybrid Search）：结合关键词匹配（BM25）和向量检索。 ② 学习 **重排序（Rerank）**：用更精细的模型对检索结果重新排序。 ③ 作业：对比“纯向量检索”vs“混合检索+重排序”的回答准确率，记录数据。 |
| **第 23-24 周** | RAG 项目部署（简历作品） | ① 把整个 RAG 系统封装成 FastAPI 服务。 ② 部署到 **阿里云/腾讯云**（用免费试用额度），生成一个公网可访问的 Demo 地址。 ③ 写一篇技术博客：**《从零搭建一个企业知识库问答系统》**，包含架构图、踩坑记录、性能数据。 |

## 📌 给零基础的你，三条“保命建议”

1. **不要同时学多个框架**：LangChain 和 Dify 选一个（推荐 LangChain，更通用），PyTorch 和 TensorFlow 都别碰（你用不到）。
2. **不要死磕数学**：矩阵乘法知道怎么回事就行，不需要手推。你的核心是**工程能力**，不是算法研究。
3. **代码必须每天写**：读 10 篇文章不如写 30 分钟代码。哪怕只是改一个参数、跑通一个示例，也算进步。
