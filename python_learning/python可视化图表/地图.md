# 地图

### 导入包

要生成地图首先要导入对应的包 `Map`

地图图表类, 用于创建地图可视化



```python
# 导包
from pyecharts.charts import Map
```



### 实例化一个地图对象

```python
map = Map()
```



### 准备数据 

```python
data = [
    ("北京市", 99),
    ("上海市", 199),
    ("湖南省", 299),
    ("广东省", 399),
]
```

**注意这里要写地区的全名, 如  “北京市”, “广东省”, 直接写 “北京”, “广东”是不行的**

### 添加数据到地图 

```python
# 添加数据
# 名称, 数据, 地图类型
map.add("测试地图", data_pair= data, maptype= "china")
```

这里的第三个参数是地图类型, “china”, 表示是中国地图

> - `"测试地图"`：系列名称（图例显示的名称）。
> - `data_pair`：传入准备好的数据。
> - `maptype="china"`：指定地图类型为中国地图（pyecharts 内置了中国地图的 GeoJSON）。 

### 配置全局选项

这里配置可视化

首先要导入可视化对应的包



```python
from pyecharts.options import VisualMapOpts
```

然后开启视觉映射图

还可以自定义分段式映射和自定义分段规则

```python
# 设置全局选项
map.set_global_opts(
    visualmap_opts= VisualMapOpts(
        # 开启视觉映射
        is_show=True,
        # 开启手动校准范围
        is_piecewise=True,
        pieces=[
            # 区间最小值
            # 区间最大值
            # 标签名称
            # 颜色代码
            {"min": 1, "max": 9, "label": "1-9", "color": "#CCFFFF"},
            {"min": 10, "max": 99, "label": "10-99", "color": "#FF6666"},
            {"min": 100, "max": 500, "label": "100-500", "color": "#990033"}
        ]
    )
)
```

### 生成图像

```python
map.render() 
```

完整代码如下: 

```python
# 导包
from pyecharts.charts import Map
from pyecharts.options import VisualMapOpts

map = Map()

data = [
    ("北京市", 99),
    ("上海市", 199),
    ("湖南省", 299),
    ("广东省", 399),
]

# 添加数据
# 名称, 数据, 地图类型
map.add("测试地图", data_pair= data, maptype= "china")

# 设置全局选项
map.set_global_opts(
    visualmap_opts= VisualMapOpts(
        # 开启视觉映射
        is_show=True,
        # 开启手动校准范围
        is_piecewise=True,
        pieces=[
            # 区间最小值
            # 区间最大值
            # 标签名称
            # 颜色代码
            {"min": 1, "max": 9, "label": "1-9", "color": "#CCFFFF"},
            {"min": 10, "max": 99, "label": "10-99", "color": "#FF6666"},
            {"min": 100, "max": 500, "label": "100-500", "color": "#990033"}
        ]
    )
)


map.render()
```
