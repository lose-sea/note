### 第一阶段：工具与基础（第1-4周）

> **目标**：能跑通开源模型，理解核心概念

| 周次      | 学习内容         | 具体任务                                           | 产出/检验                                |
| :-------- | :--------------- | :------------------------------------------------- | :--------------------------------------- |
| **第1周** | 环境搭建 + Git   | 安装WSL2/Ubuntu，配置Python虚拟环境，学Git基础命令 | 能`clone`项目并运行                      |
| **第2周** | PyTorch核心      | Tensor操作、自动求导、`nn.Module`、优化器          | 手写一个简单的线性回归训练               |
| **第3周** | Hugging Face生态 | `transformers`、`datasets`、`pipeline`             | 加载`Qwen2-0.5B`跑通文本生成             |
| **第4周** | Transformer原理  | 看《The Illustrated Transformer》+ 李宏毅视频      | 能画出Self-Attention结构图，面试能讲清楚 |

> 📖 第4周配套资料：Jay Alammar的图解Transformer + 李宏毅《生成式AI》前5集

### 🔷 第二阶段：RAG全栈开发（第5-10周）

> **目标**：独立搭建完整的RAG系统——**这是你简历上最硬的项目**

| 周次       | 学习内容       | 具体任务                                                     | 产出/检验                      |
| :--------- | :------------- | :----------------------------------------------------------- | :----------------------------- |
| **第5周**  | 文档加载与分块 | LangChain Document Loader、Text Splitter（不同chunk_size对比） | 能处理PDF/Word/Markdown        |
| **第6周**  | 向量化与检索   | 嵌入模型（`sentence-transformers`）、Chroma向量库、相似性检索 | 能对文档做Top-K检索            |
| **第7周**  | 生成链         | RetrievalQA链、ConversationalRetrievalChain、Prompt模板设计  | 能做对话式问答                 |
| **第8周**  | 高级RAG        | 多路召回、重排序（Rerank）、HyDE、父文档检索                 | 检索准确率明显提升             |
| **第9周**  | Web界面        | Streamlit / Gradio 搭建前端界面                              | 做出一个可交互的PDF问答Web应用 |
| **第10周** | 部署上线       | Docker打包 + 部署到云服务器（或AutoDL）                      | 生成一个公网可访问的URL        |

> 🏆 **阶段产出**：开源一个完整的RAG项目，写一篇技术博客发到知乎/掘金

### 🔷 第三阶段：Agent与工具调用（第11-14周）

### 🔷 第四阶段：模型微调与部署（第15-19周）

> **目标**：掌握模型定制能力，让你和其他求职者拉开差距

| 周次       | 学习内容 | 具体任务                                        | 产出/检验                          |
