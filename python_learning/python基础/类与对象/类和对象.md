

#  类和对象

类: 描述的是一组具有相同属性(特征) 和 方法 (功能/行为) 的模版

对象; 对象是类的实例, 是基于类创建出来的(实例对象) 

## 类的定义和使用

语法:  

```python
class 类名: 
    类的属性 
    
    类的行为

# 创建对象
对象名 = 类名() 
对象名.属性名1 = 属性值 
对象名.属性名2 = 属性值
```



class 关键字, 表示定义类

+ 类的属性: 定义在类中的变量 (成员变量) 
+ 类的行为: 定义在类中的函数 (成员方法)



```python
class Student:
    name = None
    age = None
    def say_hello(self):
        print(f"我是 {self.name}")

stu1 = Student()
stu1.name = "John"
stu1.say_hello() # 我是 John
```

可以看出, 类中不仅可以定义属性类记录数据, 也可以定义函数来记录行为

其中, 类中定义的属性 (变量), 我们称之为 **成员变量**

类中定义的行为 (函数), 我们称之为: **成员方法**

**说明: 类的命名规范: 遵循大驼峰命名法, 每个单词的首字母都是大写, 单词之间没有分隔符, 例如: `UserInfo, UserAccount`**

**说明: `__dict__`是python中用户自定义类实例的一个特殊属性, 用于以字典的形式存储对象的属性**  

`print(对象名.__dict__)` 以字典的形式输出属性

```python
class Car :
    pass

c1 = Car()
c1.color = "red"
c1.brand = "BMW"
c1.pirce = 5777

print(c1) # <__main__.Car object at 0x10186dfd0>
print(c1.__dict__) # {'color': 'red', 'brand': 'BMW', 'pirce': 5777}
```

## 方法

 定义在类的外面的称为函数, 定义在类中的函数称为方法

在类中定义成员方法和定义函数基本一致, 但仍有细微区别: 

```python
def 方法名(self, 形参1, ......, 形参N): 
    方法体
```

可以看到, 在方法定义的参数列表中, 有一个: self 关键字 

self 关机字是成员方法定义的时候, **必须填写**的, 

+ 它用来表示类对象自身的意思
+ 当我们使用类对象调用方法的时候, self 会自动被python 传入
+ 在方法内部, 想要访问类的成员变量, 必须使用 self  

self 关键字, 尽管在参数列表中, 但是传参的时候可以忽略它

例如: 

```python
class Student:
    name = None
    age = None
    def say_hello(self):
        print(f"我是 {self.name}")
    def print_mag(self, msg):
        print(msg)

stu1 = Student()
stu1.name = "John"
# 调用的时候无需传参
stu1.say_hello() 
# 调用的时候只需要传msg参数
stu1.print_mag("massage")
```



构造一个闹钟类

```python
class Clock:
    id = None
    price = None
    def ring(self):
        import winsound
        winsound.Beep(2200, 3000)

clock1 = Clock() 
clock1.id = 101 
clock1.price = 19.9
print(clock1.id)
clock1.ring()
```

通过 ring() 方法就可以让电脑发出声音了



## 魔术方法

魔法方法是指python中提供的以双下划线开头和结尾的方法, 用于定义类的特殊行为, 例如: `__init__`  

`__init__` 方法是在对象创建的时候自动调用的, 借此特性可以给成员变量赋值 

```python
class Student:
    name = None
    age = None
    def __init__(self, name, age):
        self.name = name
        self.age = age

stu1 = Student("John", 18)
print(stu1.__dict__) # {'name': 'John', 'age': 18}
```

注意: 

1. 构造方法`__init__`前后都有两个下划线 
2. 构造方法也是成员方法, 不要忘记在参数列表中提供 self  
3. 在方法内部使用成员变量需要使用 self  

上面讲到的 `__init__`方法是python内置的方法之一, 这些内置的方法, 各自有各自的特殊功能, 这这些内置的方法我们称之为: 魔术方法

**魔术方法不需要我们手动调用, python会在合适的时机自动调用**

| 魔术方法                               | 描述                                                     |
| -------------------------------------- | -------------------------------------------------------- |
| `__init__`                             | 初始化方法                                               |
| `__str__`                              | 字符串表示的方法                                         |
| `__eq__`                               | 比较两个对象是否相等（equal）                            |
| `__lt__`、`__le__`、`__gt__`、`__ge__` | 支持比较两个对象的大小（小于、小于等于、大于、大于等于） |



```python
class Student:
    name = None
    age = None
    def __init__(self, name, age):
        self.name = name
        self.age = age
    def __str__(self):
        return f'类对象: {self.name} {self.age}'

stu1 = Student("John", 18)
print(stu1) # 类对象: John 18
```

提供了 `__str__` 方法之后再执行 `print(stu1)`, 就不会打印再内存地址了



默认自定义的对象之间不可以进行大小比较

```python
class Car:
    def __init__(self, name, price):
        self.name = name
        self.price = price
    def running(self):
        print(f"{self.name} is running")
    def __str__(self):
        return (f"{self.name} 的价格为 {self.price}")
    def __eq__(self, other): 
        return self.name == other.name and self.price == other.price 
    def __lt__(self, other): 
        return self.price < other.price
```

不实现`__eq__` 方法, 对象之间可以比较, 但是比较的是内存地址, 即; 不同对象 == 比较一定是 False 

实现了`__eq__` 方法, 就可以按照自己的想法来决定 2 个对象是否相等了



## 属性

属性分为: 

+ 实例属性: 实力属性属于每个具体对象的属性, 每个对象都是独立的 (每个对象特有的数据) ]
+ 类属性: 类属性是属于类本身的属性, 所有实例共享的,  (所有对象共享的数据或配置)

**通过实例查找属性时, 会先查找实例属性, 实例属性不存在时, 再查找类属性**
