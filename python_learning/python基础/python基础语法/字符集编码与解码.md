# 字符集编码与解码

计算机只认识 **0** 和 **1**（二进制）。而我们人类想让它显示、存储和处理文字（比如 `A`、`你`、`@`）。

于是，我们必须制定一套**翻译规则**：

- **编码 (Encode)**：人类文字 → 计算机二进制（存储时）
- **解码 (Decode)**：计算机二进制 → 人类文字（读取时） 



**这套规则，就是“字符集”和“编码方式”**。不同的规则，就是不同的“密码本”。

### 四大“密码本”的演变历史与详解

#### 1. ASCII（美国信息交换标准代码）—— 最早的“密码本”

- **出生背景**：计算机是美国发明的，最初只需要处理英文。
- **编码规则**：用 **8个比特 (bit)**，也就是 **1个字节 (byte)** 来代表一个字符。
  - 实际上只用了低7位（128种组合），最高位始终为0。
- **能表示什么**：26个英文字母大小写、数字0-9、英文标点符号、回车、空格等。
- **特点**：**只适用于英文**。如果用它来处理中文，就会像用“英文字典”去查“汉字”一样，完全无法表示。

#### 2. GBK（汉字内码扩展规范）—— 中国的“密码本”

- **出生背景**：中国有成千上万个汉字，ASCII的1个字节最多256种组合，远远不够。我们需要一个能处理中文的“密码本”。
- **编码规则**：采用**变长编码**。
  - 英文和数字：依然使用 **1个字节**（与ASCII完全兼容，这样能读取英文文件）。
  - 中文汉字：使用 **2个字节**（16个比特），最多能表示 256 × 256 = 65536 个字符，覆盖了常用简体和繁体汉字。
- **特点**：
  - 它是 **Windows 中文版操作系统默认** 使用的编码。
  - 也是中国国家标准（GB2312的扩展）。
  - **只在中文环境内通用**，处理其他语言（如日文、韩文）会有问题。

#### 3. Unicode（统一码/万国码）—— 一统天下的“终极密码本”

- **出生背景**：世界上有中文、英文、日文、阿拉伯文...每个国家和地区都有自己的编码（GBK、Shift-JIS等）。不同密码本之间无法直接转换，**国际间交换文档全是乱码**。我们需要一个**包含全世界所有字符**的统一编码。
- **编码规则**：为世界上**每一个字符**（无论哪种语言、特殊符号、表情符号）分配一个**唯一的编号**（码点，Code Point），比如 `U+4E2D` 代表汉字“中”。
- **存储空间**：理论上，为了容纳所有字符，**Unicode 固定使用 4 个字节（32个比特）**来表示一个字符。
- **特点**:  无法使用
  - **为什么没法用？** 因为如果所有文件都按4字节存储：
    - 纯英文文件体积会瞬间膨胀4倍。
    - 大量历史数据（ASCII文件）不兼容。
  - **它的真实角色**：它现在**不用于存储和传输**，而是作为**内存中的“中间桥梁”**。程序运行时，所有文字先在内存中转换成Unicode，方便统一处理；等到要保存文件或网络传输时，再转换成其他高效编码。

#### 4. UTF-8（Unicode 转换格式 - 8位）—— 最流行的“实用密码本”

- **出生背景**：为了解决Unicode“没法用”的痛点，人们发明了UTF-8。它不是新标准，而是**对Unicode的一种高效、聪明的实现方式**。
- **编码规则**：**变长编码**。根据字符的不同，灵活使用 **1 到 4 个字节**。
  - **英文/数字**：1个字节
  - **欧洲文字（带重音符号的字母）**：2个字节
  - **常用中文（包括“你”、“好”、“世”、“界”）**：**3个字节**
  - **罕见字符（如古代汉字、特殊表情符号）**：4个字节
- **特点**：
  - **它是互联网、Linux/Mac系统、现代编程（包括Python 3）的绝对主流默认编码。**
  - 它兼顾了全球通用性和存储效率（英文不浪费空间，中文等字符又能正常表示）。  

## 核心铁律: 解码必须与编码严格匹配

**GBK 和 UTF-8 不能直接进行转化**

用UTF-8编码（加密）的字节，**必须**用UTF-8解码（解密）；用GBK编码的，**必须**用GBK解码。混用会直接报错或产生乱码。

- **唯一正确的转化路径是**：
  `UTF-8字节 --(使用UTF-8解码)--> 字符串(Unicode文字) --(使用GBK编码)--> GBK字节`

## byte

程序员平时遇见的所有的数据最终单位都是字节byte 

```python
s = '周杰伦'

bs1 = s.encode('gbk')
bs2 = s.encode('utf-8')
print(bs1) # b'\xd6\xdc\xbd\xdc\xc2\xd7'
print(bs2) # b'\xe5\x91\xa8\xe6\x9d\xb0\xe4\xbc\xa6'
print(type(bs1)) # <class 'bytes'>
```

`b 'xxxx'` 的数据类型是 bytes 类型, 上述代码打印的例如: `b'\xe5\x91\xa8\xe6\x9d\xb0\xe4\xbc\xa6'`中, 每一个`\x` 都是一个字节 

用 GBK 进行编码一个汉字是两个字节, 用 UTF-8 进行编码时,一个汉字是三个字节 

### 把一个 GBK 的字节转化为 UTF-8 的字节

```python 
bs = b'\xd6\xdc\xbd\xdc\xc2\xd7'
```

先变成文字符号 (字符串), 这里可以使用 `decode()` 进行解码

```python
bs = bs.decode('gbk')
print(bs) # 周杰伦
```

转化为文字符号后, 就可以通过`encode()`用UTF-8的方式进行编码就可以实现将GBK字节转化为UTF-8字节

```python
bs2 = bs.encode('utf8')
print(bs2) # b'\xe5\x91\xa8\xe6\x9d\xb0\xe4\xbc\xa6'
```



+ `str.encode("编码")` 进行编码
+ `bytes.decode('编码')` 进行解码
