# 包



## 包的导入 

包 : 本质就是一个文件夹, 该文件夹中可以包含若干python 模块(,python文件), 文件夹下还包含了`_ _init_ _.py` 文件

作用: 模块文件较多时,用来管理多个模块( 包的本质也是一个模块) 

| 导入形式                       | 代码样例                                | 调用方式             | 调用示例                      |
| ------------------------------ | --------------------------------------- | -------------------- | ----------------------------- |
| import 包名.模块名             | import utils.my_fun                     | 包名。模块名。功能名 | utils.my_fun.log_separator1() |
| from 包名 import 模块名        | from utils import my_fun                | 模块名。功能名       | my_fun.log_separator1()       |
| from 包名 import *             | from utils import *                     | 模块名。功能名       | my_fun.log_separator1()       |
| from 包名.模块名 import 功能名 | from utils.my_fun import log_separator1 | 功能名               | log_separator1()              |
| from 包名.模块名 import *      | from utils.my_fun import *              | 功能名               | log_separator1()              |

**在文件夹下面添加`_ _init_ _.py`才能成为软件包**

**注意: 要通过`from 名字 import * ` 导入全部模块的时候, 需要在`_ _init_ _.py`中添加`_ _add_ _ = []`控制允许导入的模块列表**



### import 包名.模块名

```python
import MyPackage.MyModel01
import MyPackage.MyModel02

MyPackage.MyModel01.info_print01()
MyPackage.MyModel02.info_print02()
```

这里也可以给导入的模块起别名

```python
import MyPackage.MyModel01 as m
import MyPackage.MyModel02 as n

m.info_print01()
n.info_print02()
```



### form 包名 import 模块名



```python\
from MyPackage import MyModel01
MyModel01.info_print01()  
```

同样可以给导入的模块起别名



```python
from MyPackage import MyModel01 as m
m.info_print01()
```



### form.包名.模块名 import 功能名 

```
from MyPackage.MyModel01 import info_print01
info_print01()
```

为导入的功能起别名

```python
from MyPackage.MyModel01 import info_print01 as m
m() 
```



### 通过`_ _all_ _` 控制 import *导入的内容

在我的包中, 我创建了两个模块

![image-20260816014912123](C:\Users\Lenovo\AppData\Roaming\Typora\typora-user-images\image-20260816014912123.png)

使用 `import *` 默认是导入所有的模块的

但是在`_ _init_ _.py` 文件中是可以通过`_ _all_ _` 控制 import *导入的模块的

例如: 

在`_ _init_ _.py` 文件中写入

```python
__all__  = ["MyModel01"]
```

然后再在main.py文件中

```python
from MyPackage import *

MyModel01.info_print01()
MyModel02.info_print02() # 报错
```

MyModel02的内容就会报错



## 第三方包

### 什么是第三方包

我们知道，包可以包含一堆的 Python 模块，而每个模块又内含许多的功能。

所以，我们可以认为：一个包，就是一堆同类型功能的集合体。

在 Python 程序的生态中，有许多非常多的第三方包（非 Python 官方），可以极大的帮助我们提高开发效率，如：

- 科学计算中常用的：numpy 包
- 数据分析中常用的：pandas 包
- 大数据计算中常用的：pyspark、apache‑flink 包
- 图形可视化常用的：matplotlib、pyecharts
- 人工智能常用的：tensorflow
- 等

这些第三方的包，极大的丰富了 Python 的生态，提高开发效率。

但是由于是第三方，所以 Python 没有内置，所以需要安装它们才可以导入使用




### 安装第三方包

# 安装第三方包 - pip

第三方包的安装非常简单，我们只需要使用 Python 内置的 pip 程序即可。

打开我们许久未见的：命令提示符程序，在里面输入：

```
pip install 包名称
```

即可通过网络快速安装第三方包
