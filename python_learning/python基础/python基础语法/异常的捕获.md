# 异常

## 什么是异常

当检测到一个错误的时候, python解释器就无法继续执行了, 反而出现了一些错误的提示, 这就是所谓的异常, 也就是我们常说的bug

## 为什么要捕获异常

当我们的程序遇到了bug, 那么接下来有两种情况

1. ① 整个程序因为一个bug停止运行
2. ② 对bug进行提示, 整个程序继续运行

在之前的学习中, 我们所有的程序遇到bug 就会出现整个程序停止运行的情况, 也就是整文个程序直接奔溃

但是在真实的工作中, 我们不能因为一个小的bug就让整个程序全部奔溃, 也就是我们希望的达到 ② 的这种情况, 那这里我们就需要使用到捕获异常 

**捕获异常的作用在于: 提前假设某处会出现异常, 做好提前准备, 当整的出现异常的时候, 可以有后续手段**

## 异常捕获 

### 捕获常规异常

基本语法: 

```python
try: 
    可能发生错误的代码
except: 
    如果出现异常执行的代码
```

例子: 

当打开文件的时候,以只读 ‘r’ 的模式打开, 文件不存在,就会报错, 就需要以 ‘w’ 的模式打开

```python
try:
    f = open("python.txt", "r")
except:
    print("出现了异常, 文件不存在, 改用 w 模式打开")
    f = open("python.txt", "w")
    f.write("python")
```

### 捕获指定异常

变量未定义的异常

```python
try:
    print(name)
except NameError as e:
    print("出现了变量未定义的异常")
    print(e)
    print(type(e))
```



输出: 

```
出现了变量未定义的异常
name 'name' is not defined
<class 'NameError'>
```

这里的 e 是我们设置的异常的别名,就是异常的对象, 记录了异常的具体信息

这种方式只会捕获NameError 的异常, 不会捕获其他异常

例如: 

```python
try:
    1 / 0
except NameError as e:
    print("error")
```

1 / 0 属于是 `ZeroDivisionError` 的异常, 用`NameError` 无法捕获到 

### 捕获多个异常

当捕获多个异常的时候, 可以把要捕获的异常的类型的名字, 放在except 后, 并使用元组的方式尽进行书写

例如: 

```python
try:
    print(1 / 0)
except (NameError, ZeroDivisionError): 
    print("ZeroDivision 错误")
```

注意: 未正确设置捕获异常类型, 将无法捕获异常 

### 捕获所有异常

语法: 

```python
try: 
    可能发生错误的代码
except Exception as e: 
    如果出现异常执行的代码
```

例如: 

```python
try:
    print(name)
    print(1 / 0)
except Exception as e:
    print(e)
```

这种写法与上面所讲的第一种方式是等价的

```python
try: 
    可能发生错误的代码
except: 
    如果出现异常执行的代码
```

## 异常else

当没有发生异常时候会执行

例如: 

```python
name = "John"
try:
    print(name)
except Exception as e:
    print(e)
else :
    print("没有出现异常")
```

## 异常的 finally 

finally 表示的是无论是否异常都要执行的代码, 例如关闭文件

例如: 

```python
try:
    f = open("python.txt","r", encoding = "utf-8")
except Exception as e:
    print(e)
else:
    print("没有出现异常")
finally:
    print("close 文件")
    f.close() 
```

## 总结

捕获异常的语法: 

```python
try: 
    可能发生异常的代码
except 异常 as 别名: 
    出现异常执行的语句
else: 
    没有出现异常执行的语句
finally: 
    无论是否出现异常都要执行的语句 
```

异常的种类是多种多样的, 如果想要不管什么类型的异常都能捕获到, 那么使用: 

1. except: 
2. except Exception as 别名: 

一般使用第二种写法
