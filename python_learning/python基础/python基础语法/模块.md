# 模块(module)

python模块(module): 一个.py文件就是一个模块, 模块是python 程序的基本组织单位, 在模块中可以定义变量.函数, 类 ,以及可执行的代码

## 模块的作用

python 中有很多各种不同的模块，每一个模块都可以帮助我们快速的实现一些功能，比如实现和时间相关的功能就可以使用 time 模块

我们可以认为一个模块就是一个工具包，每一个工具包中都有各种不同的工具供我们使用进而实现各种不同的功能



## 模块的导入



+ 在使用模块中提供的功能之前，必须得先导入，再使用。
+ 导入模块的具体语法如下：

| 导入形式                        | 代码样例                           | 调用方式      | 调用方式示例            |
| ------------------------------- | ---------------------------------- | ------------- | ----------------------- |
| import 模块名                   | import random, os                  | 模块名.功能名 | random.randint(10, 100) |
| import 模块名 as 别名           | import random as rd                | 别名.功能名   | rd.randint(10, 100)     |
| from 模块名 import 功能名       | from random import randint,choice  | 功能名        | randint(10, 100)        |
| from 模块名 import 功能名 as 名 | from random import randint as rint | 别名          | rint(10, 100)           |
| from 模块名 import *            | from random import *               | 功能名        | randint(10, 100)        |



## 导入模块

#### 使用import 导入time模块使用sleep功能

```python
# 导入python内置的time模块
import time
print("hello world")
# 程序暂停 3 秒种
time.sleep(3)
print("hello xinyan")
```

通过 `.` 就可以使用模块内的全部功能(类, 函数, 变量)

#### 使用from 导入time的sleep功能

基本语法
```python
from 模块名 import 功能名 

功能名() 
```



例如: 

```python
from time import sleep
print("开始")
sleep(2)
print("hello xinyan")
```

#### 导入模块中所有的方法

基本语法: 

```python
from 模块名 import *

功能名() 
```

 例如: 

```python
from time import *
print("开始")
sleep(2)
print("hello xinyan")
```

### as 别名 

基本语法: 

模块定义别名

`import 模块名 as 别名`

功能定义别名

`form 模块名 import 功能 as 别名`

例如: 

模块别名

```python
import  time as tt
print("开始")
tt.sleep(2)
print("hello xinyan")
```



功能别名

```python
from time import sleep as tt
print("开始")
tt(2)
print("hello xinyan")
```

**模块的导入一般写在代码文件的开头位置 **



## 自定义模块

当开发一些复杂的项目, 为了让项目结构更加清晰, 更便于项目的维护管理以及代码的复用, 可能把一个项目拆分为若干个模块

> 每个python文件都可以作为一个模块, 模块的名称就是文件的名字(建议使用python标识符定义,规范命名) 

**常量的名称是大写**

自定义模块的使用 

```python
MyModel.py

def add(a,b):
    print(a+b)
    return a+b
```



```python
main.py

import MyModel as my_function
a = 23
b = 32
my_function.add(a, b)
```



>  注意: 不同模块, 同名的功能, 如果都被导入, 那么后导入的会覆盖先导入的



**`_ _name_ _`是python中的内置变量, 表示当前模块的名字**

```python
import my_fun

print(my_fun.log_separator1())
print(my_fun.log_separator2())
print(my_fun.log_separator3())
print(my_fun.log_separator4())

print(__name__) 

if __name__ == "__main__": 	# 判断
    my_fun.log_separator1()
```



`if __name__ == '__main__':` 表示, 只有当程序是直执行才会进入if 内部, 如果是被导入的, 则if无法进入 

**`_ _all_ _`是一个模块级别的特殊变量, 用于指定 from 模块名 import \*  时会导入哪些功能**

```python
my_fun.py 

__all__ = ["log_separator1", "log_separator2"]
```



`_ _all_ _ `变量可以控制`import *` 的时候哪些功能可以被导入
