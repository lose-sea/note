函数是组织好的, 可重复使用的, 用来实现特定功能的代码片段

## 函数的定义和调用

```python
# 定义函数
def 函数名 (参数列表): 
    函数体
    ......
    return 返回值

# 调用函数
函数名 (参数)
```

函数定义时的参数列表与返回值语句是可有可无的(有需求确定, 函数必须先定义后调用执行 (函数定义时, 内部代码并未执行, 在调用时才执行) 

### 函数使用的注意事项 

1. 函数必须先定义, 再调用
2. 函数定义时, 并不会执行, 只有再调用函数时, 函数体的逻辑才会运行 
3. 函数中通过缩进来描述归属关系

## 参数, 返回值

函数可以有多个参数, **也可以有多个返回值**

多个返回值的封装到元组中

```python
## 计算圆的面积和周长
## 多个返回值
def circle_area_len(r):
    return round(3.14 * r * r), round(2 * 3.14 * r)  

a1 = circle_area_len(10) 

print(a1) # (314, 63)
print(type(a1)) # <class 'tuple'>
```

round 表示四舍五入

```python
round(数字, 保留位数)
```

## 函数的嵌套调用

函数调用指的是在一个函数中, 又调用了另外一个函数 

函数调用遵循栈结构, 最后被调用的函数最先返回LIFO(Last In First Out, 后进先出) 

## 函数-变量作用域 

变量的作用域指的是变量的作用范围 (标识这个变量在哪里可以使用, 在哪里不可以使用) 

全局变量: 在函数之外定义的变量, 称为全局变量, 在整个文件中 (包括函数内) 都可以使用 (通常定义在文件的顶部) 

局部变量; 在函数的内部定义的变量, 成为局部变量, 只能在该函数内部使用, 外部无法访问(函数执行完毕后, 会自动销毁其内部局部变量) 

局部变量会覆盖全局变量 

### global 关键字

global 关键字用于明确告诉python 解释器, 在函数中要使用全局变量, 使得可以在函数内部修改全局变量的值 

```python
# 全局变量：在函数外部、或函数的内部都是可以访问的；
num = 100

# 定义函数
def circle_area(r):

    pi = 3.14
    area = pi * r * r

# 调用函数
c_area = circle_area(10)
```

示例如下: 

```python
# 定义函数
def circle_area(r):
    # 局部变量：只能在函数内部使用
    pi = 3.14
    area = pi * r * r 

    global num
    num = 10000
    print("num = ", num)  # 10000

    return area

# 调用函数
c_area = circle_area(10)
print(c_area)

print("num = ", num)  # 10000
```

可以看到, 在使用了global之后, 全局变量发生的修改

#### **注意事项: **

1. 尽量避免在函数中使用全局变量, 因为会是代码难以维护和调试
2. 考虑使用函数参数和返回值来传递数据,而不是依赖全局变量
3. global 主要用在程序的状态, 配置和计数器等场景中

## 函数-传参方式

### 位置参数: 调用函数时根据函数定义时的位置来传递参数

调用函数时参数顺序与定义函数时参数顺序完全一致

### 关键字参数: 调用函数时以函数定义时形参名称作为关键字, 以“键 = 值” 的形式来传递参数 (不要求顺序)

**如果位置参数与关键字参数混用, 关键字参数必须在位置参数之后(关键字参数之间没有顺序要求)**

## 函数的默认参数 (缺省参数)

默认参数也成为缺省参数, 用于定义函数时, 为参数提供默认值, 调用函数时, 可以不传递有默认值的参数

**注意: 默认参数必须放在没有默认值的参数列表的后面, 一个函数在定义时是可以设置多个默认参数的**

如果使用默认参数, 如果没有按照顺序, 就需要使用关键字参数

## 不定长参数

不定长参数也叫做可变参数, 用于函数定义及调用时参数个数不确定(0 个或多个) 的场景

类型: 位置传递, 关键字传递 

### 基于位置传参的不定长参数(*args)



```python
定义函数: 
del calc_data(*args): 
```

传递的所有匹配的位置参数都会被args 变量收集, 这些参数会合并并封装为一个元组, args是元组(tuple)类型 (注意并不会封装关键字参数)

args 只是约定俗称的变量名, 并不是关键字, 这里可以使用任何合法的变量名 (如 * data) 

```objc
def test(*args):
    print(args)

test(13, "johm", "hello")
```



### 基于关键字传参的不定长参数 (kwargs)

参数是以“键 = 值 ” 形式传递的关键字参数, 这些“键 = 值” 参数都会被kwargs接受, 并**合并封装为一个字典类型**

```python
def test(**kwargs):
    print(kwargs)

test(name = "john", age = 18, gender = "male") 
        # {'name': 'john', 'age': 18, 'gender': 'male'}
```

## 匿名函数

匿名函数指的是没有名称的函数, 需要通过lambda表达式来声明函数, 可以简化简单函数的编写 (单行表达式)

定义: 

```python
lambda 参数列表 : 函数体
```

### 使用场景:

+ 函数逻辑比较简单(单行表达式)且只在一个地方使用时, 可以考虑使用匿名函数, 简化书写
+ 匿名函数中可以返回结果, 也可以不写返回结果, 不需要写return, 表达式的运行结果就是要返回的结果

匿名函数不可以写 return, 会自动返回

```python
# 打印hello 
# 无参数的匿名函数
out_line=  lambda: print("hello")
out_line()

# 有参数匿名函数
add = lambda x, y: x + y 
print(add(100, 200))
```

## 类型注解

类型注解时python 中的一种语法特性, 用于明确标识变量, 函数参数和返回值的数据类型, 从而使代码更清晰, 更安全, 更易维护

```objc
# 变量定义 - 指定类型注解
a2: int = 596
score2: float = 98.5
hobby2: str = "Python"
flag2: bool = True
pic2: None = None

names2: list[str | int] = ["A", "C", "E"]
phones2: set[str] = {"13309091111", "15209101902", "18809019201"}
options2: dict[str, int] = {"count":2, "total":10}
goods2: tuple[str, int, int] = ("手机", 6999, 1)

names2.append("X")
names2.append(10010)
names2.append(10010.0)
```

上面的`names2: list[str | int] = ["A", "C", "E"]` 表示names2可以存储 int 或者 str 类型的值

## 类型推断

类型推断是指python 解释器自动推断出变量, 表达式或函数返回值的数据类型的能力,而无需开发者显示声明

在对变量进行直接赋值, 或者涉及到变量的运算, 容器的推导等场景时, 解释器会自动推导出变变量的类型 

**类型注解只是起到语法提示作用, 并不能影响程序的运行的结果**

Python是动态类型语言, 添加的类型注解只是提示,并不是强制约束.

## 函数的类型注解

为函数添加类型注解,其实主要是为函数的参数和返回值添加类型注解, 具体语法如下: 

```objc
def calc_data(score: list[int]) -> tuple[int, int, int] 
    			参数类型				返回值类型
```
