## 今日算法题

### 题目1: [538. 把二叉搜索树转换为累加树](https://leetcode.cn/problems/convert-bst-to-greater-tree/) 

![image-20260614214450609](/Users/lose_sea/Desktop/pintures/image-20260614214450609.png)

```objc
class Solution {
public:  
    int pre = 0; 
    void  traversal(TreeNode* root) {
        if (root == nullptr) {
            return; 
        } 
        traversal(root->right); 
        root->val += pre;  
        pre = root->val; 
        traversal(root->left); 
    }
        TreeNode* convertBST(TreeNode* root) {
        if (root == nullptr) {
            return nullptr; 
        } 
        traversal(root); 
        return root; 
    }
};
```
