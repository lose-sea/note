## 今日算法题

### 题目1: [108. 将有序数组转换为二叉搜索树](https://leetcode.cn/problems/convert-sorted-array-to-binary-search-tree/) 

![image-20260611214415076](/Users/lose_sea/Desktop/pintures/image-20260611214415076.png)

```objc
class Solution {
public: 
    TreeNode* traversal(vector<int>& nums, int left, int right) {
        if (left >= right) {
            return nullptr;  
        } 
        int mid = left + (right - left) / 2; 
        TreeNode* node = new TreeNode(nums[mid]); 
        node->left = traversal(nums, left, mid); 
        node->right = traversal(nums, mid + 1, right); 
        return node; 
    }
    
    TreeNode* sortedArrayToBST(vector<int>& nums) {
        if (nums.empty()) {
            return nullptr; 
        } 
        return traversal(nums, 0, nums.size()); 
    }
};
```
