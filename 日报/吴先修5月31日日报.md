## 今日算法题

### 题目1: [654. 最大二叉树](https://leetcode.cn/problems/maximum-binary-tree/) 

![image-20260531214811886](/Users/lose_sea/Desktop/pintures/image-20260531214811886.png)

```objc
class Solution {
public:
    TreeNode* traversal(vector<int>& nums) {
        if (nums.empty()) {
            return nullptr; 
        }
        int max = nums.front(); 
        for (int i = 0; i < nums.size(); i++) {
            if (max < nums[i]) {
                max = nums[i]; 
            }
        } 
        TreeNode* root = new TreeNode(max); 
        auto it = find(nums.begin(), nums.end(), max); 
        int delimiterIndex = it - nums.begin(); 
        vector<int> left(nums.begin(), nums.begin() + delimiterIndex); 
        vector<int> right(nums.begin() + delimiterIndex + 1, nums.end()); 
        root->left = traversal(left); 
        root->right = traversal(right); 
        return root;    
    }
    TreeNode* constructMaximumBinaryTree(vector<int>& nums) {
        if (nums.empty()) {
            return nullptr; 
        } 
        return traversal(nums); 
    }
};
```

## 本日遇到的问题

1. 在设置当键盘出现的时候界面整体上一的时候, 不知道怎么获取键盘的高度
2. 界面上移之后,出现新的视图, 导致键盘的背景颜色和原来的背景视图颜色不一致, 考虑直接调整UIWindow的背景颜色,但是由于有好多视图控制器都使用同一个UIWindow, 并且背景颜色都不一致, 这样修改不合适, 最后选择通过新添加一个 UIView, 添加到原来的背景视图上, 并设置颜色与原来的背景视图一致, 原来背景视图的子视图添加到新设置的 UIView 上, 这样在键盘出现的时候移动新添加的视图就不会导致颜色不一致而无法修改了
