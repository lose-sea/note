## 今日算法题

### 题目1:  [701. 二叉搜索树中的插入操作](https://leetcode.cn/problems/insert-into-a-binary-search-tree/) 

![image-20260609210950295](/Users/lose_sea/Desktop/pintures/image-20260609210950295.png)

```objc

class Solution {
public:
    TreeNode* insertIntoBST(TreeNode* root, int val) {
        TreeNode* node = new TreeNode(val); 
        if (root == nullptr) {
            return node; 
        } 
        TreeNode* curr = root; 
        TreeNode* pre = root; 
        while (curr) {
            pre = curr; 
            if (val < curr->val) {
                curr = curr->left;  
            } else {
                curr = curr->right; 
            }
        } 
        if (val < pre->val) {
            pre->left = node; 
        } else {
            pre->right = node; 
        } 
        return root; 
    } 
};
```
