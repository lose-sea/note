## 今日算法题

### 题目1:  [700. 二叉搜索树中的搜索](https://leetcode.cn/problems/search-in-a-binary-search-tree/) 

![image-20260520214015633](/Users/lose_sea/Desktop/pintures/image-20260520214015633.png)

```objc
class Solution {
public: 
    TreeNode* traversal(TreeNode* root, int val) {
        if (root == nullptr) {
            return nullptr; 
        } 
        if (root->val == val) {
            return root; 
        } else if (val < root->val) {
            return traversal(root->left, val); 
        } 
        return traversal(root->right, val); 
    }
    TreeNode* searchBST(TreeNode* root, int val) {
        if (root == nullptr) {
            return nullptr; 
        } 
        return traversal(root, val); 
    }
};
```
