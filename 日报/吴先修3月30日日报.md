## 题目1: [560. 和为 K 的子数组](https://leetcode.cn/problems/subarray-sum-equals-k/)

![image-20260330214311831](/Users/lose_sea/Library/Application Support/typora-user-images/image-20260330214311831.png)

```objc
class Solution {
public:
    int subarraySum(vector<int>& nums, int k) {  
        int result = 0;  
        int len = nums.size(); 
        vector<int> s(len + 1); 
        s[0] = 0;  
        for (int i = 0; i < nums.size(); i++) {
            s[i + 1] = s[i] + nums[i]; 
        } 
        unordered_map<int, int> mp; 
        for (int i = 0; i < s.size(); i++) {
            if (mp.contains(s[i] - k)) { 
                result += mp[s[i] - k];  
            }  
            mp[s[i]]++; 
        }  
        return result; 
    }
};
```
