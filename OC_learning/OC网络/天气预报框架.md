整体效果类似 **iOS 天气 App**，主要包含以下几个模块：

1. 顶部城市信息
   + 城市名
   + 当前温度（大号字体）
   + 天气描述
   + 最高/最低温
2. 蓝色渐变背景
   + 根据天气变化
   + 带一点毛玻璃效果
3. 24 小时天气（横向滚动）
4. 未来天气（竖向列表）
5. 搜索城市
   + 输入关键字
   + UITableView 显示匹配城市
   + 点击进入天气页面

------

## 如果你想**自己实现**，我建议不要一次全部写，而是按照苹果天气的开发顺序。

### 第一阶段（你已经完成了 40%）

✅ 城市搜索

✅ 经纬度查询

✅ 天气 API

✅ 能获取 JSON

------

### 第二阶段（现在应该做）

先把天气数据显示出来。

例如：

```
西安市

32°

晴

H:35°  L:24°
```

增加几个控件：

```
@property(nonatomic,strong)UILabel *cityLabel;

@property(nonatomic,strong)UILabel *tempLabel;

@property(nonatomic,strong)UILabel *weatherLabel;

@property(nonatomic,strong)UILabel *maxMinLabel;

@property(nonatomic,strong)UIImageView *weatherImageView;
```

点击城市后：

```
requestWeather
        ↓
解析JSON
        ↓
更新UILabel
```

这是最重要的一步。

------

### 第三阶段

增加未来天气列表。

你的 API 已经有：

```
daily
```

所以直接可以做：

```
UITableView

今天    ☀️   35° 24°

明天    🌧   31° 22°

周四    ☁️   30° 21°
```

这个 UITableView 和你现在搜索城市的 UITableView 写法几乎一样。

------

### 第四阶段

增加 24 小时天气。

使用：

```
UICollectionView
```

横向滚动。

效果：

```
13:00 ☀️ 31°

14:00 ☀️ 32°

```

```
weather_code
```

蓝色背景


### 第六阶段（视频里的效果）

做背景动画。

可以使用：

+ `CAGradientLayer`
+ `UIVisualEffectView`
+ `Lottie`
+ `CAEmitterLayer`

这些都可以逐步加入。

## 我建议你的项目结构

目前你的所有代码都写在 `ViewController.m` 里面，随着功能增加会越来越难维护。建议从现在开始拆分类。

例如：

```
Weather
│
├── Model
│     WeatherModel
│     DailyWeatherModel
│     HourlyWeatherModel
│
├── View
│     WeatherHeaderView
│     HourlyCell
│     DailyCell
│
├── Controller
│     SearchViewController
│     WeatherViewController
│
└── Network
      WeatherManager
```

这样后面增加功能会轻松很多。
