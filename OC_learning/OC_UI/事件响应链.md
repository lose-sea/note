# 事件响应链 

OC 里 **UI 事件响应链（Responder Chain）** 是学习触摸事件的核心。可以把它理解成：

**事件从“最合适的人”开始处理，如果不处理，就往上层一层一层传递。** 

### 响应链传递顺序

View
⬆
父 View（superview）
⬆
UIViewController
⬆
UIWindow
⬆
UIApplication
⬆
AppDelegate 



## 命中测试顺序:

用户点击屏幕
      ↓
  命中测试（hitTest）
      ↓
  最内层 UIView
      ↓
  superview
      ↓
  UIViewController
      ↓
  UIWindow
      ↓
  UIApplication
      ↓
  AppDelegate



**事件处理分两步：**

**命中测试（hitTest）**
  从 `UIWindow` 向下查找，找到**最合适的 View**

**响应链传递（Responder Chain）**
  从该 View 开始，**向上传递**，直到有人处理

## 响应链传递顺序

```
UIView
⬆
superview（父视图）
⬆
UIViewController
⬆
UIWindow
⬆
UIApplication
⬆
AppDelegate
```

**View → 父View → 控制器 → Window → Application → AppDelegate**

命中测试是自上而下，响应链传递是自下而上
