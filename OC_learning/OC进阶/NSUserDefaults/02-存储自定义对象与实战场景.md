# 02 - 存储自定义对象与实战场景

在实际开发中，我们经常会有这样的需求：“我写了一个 `UserModel` 类，怎么把它存进 `NSUserDefaults`？”

如果你直接这样写：
```objc
UserModel *user = [[UserModel alloc] init];
user.name = @"小明";
// ❌ 崩溃！NSInvalidArgumentException: Attempt to insert non-property list object
[[NSUserDefaults standardUserDefaults] setObject:user forKey:@"currentUser"];
```
App 会立刻崩溃！因为 `NSUserDefaults` 不认识你自己定义的类。

下面介绍 **两种最常用的解决方案**，以及 **4 个真实开发实战场景**。

---

## 一、存储自定义对象的两种方案

假设我们有一个自定义模型类 `CityModel`：

```objc
// CityModel.h
@interface CityModel : NSObject
@property (nonatomic, copy) NSString *cityName;
@property (nonatomic, assign) double latitude;
@property (nonatomic, assign) double longitude;
@end
```

### 方案 1：转成 `NSDictionary`（推荐新手使用，最简单直观）

思路：**存之前**把对象变成字典，**取出来**再把字典还原成对象。

```objc
// CityModel.h 中声明转换方法
@interface CityModel : NSObject
@property (nonatomic, copy) NSString *cityName;
@property (nonatomic, assign) double latitude;
@property (nonatomic, assign) double longitude;

- (NSDictionary *)toDictionary;
+ (instancetype)modelWithDictionary:(NSDictionary *)dict;
@end

// CityModel.m 中实现
@implementation CityModel

- (NSDictionary *)toDictionary {
    return @{
        @"cityName": self.cityName ?: @"", // 防止 nil 导致字面量字典崩溃！
        @"latitude": @(self.latitude),
        @"longitude": @(self.longitude)
    };
}

+ (instancetype)modelWithDictionary:(NSDictionary *)dict {
    if (![dict isKindOfClass:[NSDictionary class]]) return nil;
    CityModel *model = [[CityModel alloc] init];
    model.cityName = dict[@"cityName"];
    model.latitude = [dict[@"latitude"] doubleValue];
    model.longitude = [dict[@"longitude"] doubleValue];
    return model;
}

@end
```

**存取使用方式**：
```objc
// 存单个对象
CityModel *xian = [[CityModel alloc] init];
xian.cityName = @"西安";
xian.latitude = 34.26;
xian.longitude = 108.94;
[[NSUserDefaults standardUserDefaults] setObject:[xian toDictionary] forKey:@"defaultCity"];

// 取单个对象
NSDictionary *dict = [[NSUserDefaults standardUserDefaults] dictionaryForKey:@"defaultCity"];
CityModel *savedCity = [CityModel modelWithDictionary:dict];
```

- **优点**：打开沙盒 `.plist` 文件能直接看懂明文内容，调试方便；代码简单不易出错；增删字段兼容性好。
- **缺点**：如果属性特别多，手写转换字典有点繁琐（项目中常配合 `YYModel` / `MJExtension` 自动转字典）。

---

### 方案 2：`NSSecureCoding` 归档成 `NSData`（官方标准序列化方案）

思路：让自定义类遵守 `NSSecureCoding` 协议，用 `NSKeyedArchiver` 把对象打包成二进制 `NSData` 存进去，读取时用 `NSKeyedUnarchiver` 解包。

> **注意**：老教程里常用 `NSCoding` + `archivedDataWithRootObject:`，这些方法在 iOS 12+ 已被标记废弃（Deprecated）。现在统一使用更安全的 **`NSSecureCoding`**。

```objc
// CityModel.h
@interface CityModel : NSObject <NSSecureCoding>
@property (nonatomic, copy) NSString *cityName;
@property (nonatomic, assign) double latitude;
@property (nonatomic, assign) double longitude;
@end

// CityModel.m
@implementation CityModel

// 1. 必须实现：声明支持安全编码
+ (BOOL)supportsSecureCoding {
    return YES;
}

// 2. 编码（存数据时系统自动调用）
- (void)encodeWithCoder:(NSCoder *)coder {
    [coder encodeObject:self.cityName forKey:@"cityName"];
    [coder encodeDouble:self.latitude forKey:@"latitude"];
    [coder encodeDouble:self.longitude forKey:@"longitude"];
}

// 3. 解码（取数据时系统自动调用）
- (instancetype)initWithCoder:(NSCoder *)coder {
    self = [super init];
    if (self) {
        // NSSecureCoding 要求解码对象时必须指定类型
        _cityName = [coder decodeObjectOfClass:[NSString class] forKey:@"cityName"];
        _latitude = [coder decodeDoubleForKey:@"latitude"];
        _longitude = [coder decodeDoubleForKey:@"longitude"];
    }
    return self;
}

@end
```

**存取单个对象**：
```objc
// 存：归档为 NSData
NSError *archiveError = nil;
NSData *data = [NSKeyedArchiver archivedDataWithRootObject:xian
                                     requiringSecureCoding:YES
                                                     error:&archiveError];
if (data) {
    [[NSUserDefaults standardUserDefaults] setObject:data forKey:@"archivedCity"];
}

// 取：从 NSData 解档
NSData *savedData = [[NSUserDefaults standardUserDefaults] dataForKey:@"archivedCity"];
if (savedData) {
    NSError *unarchiveError = nil;
    CityModel *city = [NSKeyedUnarchiver unarchivedObjectOfClass:[CityModel class]
                                                        fromData:savedData
                                                           error:&unarchiveError];
    NSLog(@"解档结果：%@", city.cityName);
}
```

**存取自定义对象数组（例如 `NSArray<CityModel *>`）**：
解档数组时，需要把 `NSArray` 和 `CityModel` 都放进允许的类集合中：
```objc
// 存数组
NSData *arrayData = [NSKeyedArchiver archivedDataWithRootObject:cityArray
                                          requiringSecureCoding:YES
                                                          error:nil];
[[NSUserDefaults standardUserDefaults] setObject:arrayData forKey:@"savedCitiesData"];

// 取数组
NSData *loadedData = [[NSUserDefaults standardUserDefaults] dataForKey:@"savedCitiesData"];
if (loadedData) {
    NSSet *allowedClasses = [NSSet setWithObjects:[NSArray class], [CityModel class], nil];
    NSArray<CityModel *> *cities = [NSKeyedUnarchiver unarchivedObjectOfClasses:allowedClasses
                                                                       fromData:loadedData
                                                                          error:nil];
}
```

## 二、4 个真实开发实战场景

### 场景 1：判断 App 是否首次启动 / 版本更新引导页

几乎每个 App 都需要这个功能：新用户第一次安装，或者更新到大版本后，展示欢迎引导页。

```objc
- (BOOL)shouldShowOnboarding {
    NSUserDefaults *defaults = [NSUserDefaults standardUserDefaults];
    
    // 获取当前 App 的版本号（例如 @"1.2.0"）
    NSString *currentVersion = [[NSBundle mainBundle] objectForInfoDictionaryKey:@"CFBundleShortVersionString"];
    // 获取上次运行记录的版本号
    NSString *lastVersion = [defaults stringForKey:@"LastLaunchedAppVersion"];
    
    if (![currentVersion isEqualToString:lastVersion]) {
        // 首次安装（lastVersion 为 nil）或版本已更新
        [defaults setObject:currentVersion forKey:@"LastLaunchedAppVersion"];
        return YES;
    }
    return NO;
}
```

### 场景 2：保存设置页的 `UISwitch` 开关状态

```objc
// 页面加载时恢复开关状态
- (void)viewDidLoad {
    [super viewDidLoad];
    BOOL isNightMode = [[NSUserDefaults standardUserDefaults] boolForKey:@"isNightMode"];
    self.nightModeSwitch.on = isNightMode;
}

// 用户点击开关时立即保存
- (IBAction)nightModeSwitchChanged:(UISwitch *)sender {
    [[NSUserDefaults standardUserDefaults] setBool:sender.isOn forKey:@"isNightMode"];
    [self applyTheme:sender.isOn];
}
```

### 场景 3：保存最近 10 条搜索历史（带去重和数量限制）

```objc
static NSString * const kSearchHistoryKey = @"SearchHistoryList";

// 添加一条搜索记录
- (void)addSearchKeyword:(NSString *)keyword {
    if (keyword.length == 0) return;
    
    NSUserDefaults *defaults = [NSUserDefaults standardUserDefaults];
    // ⚠️ 重点：取出来的数组是不可变的，必须 mutableCopy 才能修改！
    NSArray *saved = [defaults stringArrayForKey:kSearchHistoryKey];
    NSMutableArray *history = saved ? [saved mutableCopy] : [NSMutableArray array];
    
    // 如果已存在，先移除旧位置，再插到最前面
    [history removeObject:keyword];
    [history insertObject:keyword atIndex:0];
    
    // 最多只保留 10 条，防止无限膨胀
    if (history.count > 10) {
        [history removeObjectsInRange:NSMakeRange(10, history.count - 10)];
    }
    
    [defaults setObject:[history copy] forKey:kSearchHistoryKey];
}

// 读取搜索历史
- (NSArray<NSString *> *)loadSearchHistory {
    return [[NSUserDefaults standardUserDefaults] stringArrayForKey:kSearchHistoryKey] ?: @[];
}

// 清空搜索历史
- (void)clearSearchHistory {
    [[NSUserDefaults standardUserDefaults] removeObjectForKey:kSearchHistoryKey];
}
```

### 场景 4：工程化封装 —— 告别满屏硬编码字符串 Key

在真实项目里，不要到处散落 `@"isNightMode"` 这样的字符串（万一某个地方拼成 `@"isNigthMode"`，排查半天找不到 Bug）。

推荐封装一个统一的管理类，用**属性**来读写 `NSUserDefaults`：

```objc
// AppSettings.h
#import <Foundation/Foundation.h>

@interface AppSettings : NSObject

+ (instancetype)shared;

@property (nonatomic, assign) BOOL isNightMode;
@property (nonatomic, copy, nullable) NSString *lastUsername;
@property (nonatomic, assign) NSInteger fontSize;

- (void)registerDefaultSettings;

@end
```

```objc
// AppSettings.m
#import "AppSettings.h"

static NSString * const kIsNightModeKey  = @"com.myapp.settings.isNightMode";
static NSString * const kLastUsernameKey = @"com.myapp.settings.lastUsername";
static NSString * const kFontSizeKey     = @"com.myapp.settings.fontSize";

@implementation AppSettings

+ (instancetype)shared {
    static AppSettings *instance = nil;
    static dispatch_once_t onceToken;
    dispatch_once(&onceToken, ^{
        instance = [[AppSettings alloc] init];
    });
    return instance;
}

- (void)registerDefaultSettings {
    [[NSUserDefaults standardUserDefaults] registerDefaults:@{
        kIsNightModeKey: @NO,
        kFontSizeKey: @16
    }];
}

#pragma mark - Getter & Setter

- (BOOL)isNightMode {
    return [[NSUserDefaults standardUserDefaults] boolForKey:kIsNightModeKey];
}

- (void)setIsNightMode:(BOOL)isNightMode {
    [[NSUserDefaults standardUserDefaults] setBool:isNightMode forKey:kIsNightModeKey];
}

- (NSString *)lastUsername {
    return [[NSUserDefaults standardUserDefaults] stringForKey:kLastUsernameKey];
}

- (void)setLastUsername:(NSString *)lastUsername {
    [[NSUserDefaults standardUserDefaults] setObject:lastUsername forKey:kLastUsernameKey];
}

- (NSInteger)fontSize {
    return [[NSUserDefaults standardUserDefaults] integerForKey:kFontSizeKey];
}

- (void)setFontSize:(NSInteger)fontSize {
    [[NSUserDefaults standardUserDefaults] setInteger:fontSize forKey:kFontSizeKey];
}

@end
```

封装之后，业务代码里用起来极其清爽、有编译期检查、不怕拼错 Key：
```objc
// 读取
BOOL dark = [AppSettings shared].isNightMode;
// 修改
[AppSettings shared].isNightMode = YES;
```
