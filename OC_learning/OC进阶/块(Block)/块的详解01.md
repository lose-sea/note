# Objective-C Block 详解

Block 是 OC 中非常核心的语法，AFNetworking 的回调、GCD、动画、通知等都大量使用。下面从语法到内存、捕获、循环引用，系统讲一遍。

------

## 一、Block 是什么

Block 是**封装了一段代码的匿名对象**，可以像变量一样传递、存储、调用。本质是"带上下文的函数"。

### 1. 基本语法

```objc
// 声明 + 赋值
返回值类型 (^block变量名)(参数类型列表) = ^返回值类型(参数列表) {
    // 代码
};

// 最简单的无参无返回
void (^simpleBlock)(void) = ^{
    NSLog(@"hello block");
};
simpleBlock();   // 调用

// 带参数带返回
int (^addBlock)(int, int) = ^int(int a, int b) {
    return a + b;
};
int result = addBlock(3, 5);  // 8
NSLog(@"%d", result);
```



### 2. 语法记忆技巧



```
返回值类型 (^名字)(参数类型) = ^(参数名){ 代码 };
```



**返回值类型可以省略**，编译器会自动推断：



```
int (^addBlock)(int, int) = ^(int a, int b) {
    return a + b;   // 编译器知道返回 int
};
```



### 3. 用 typedef 简化（项目里最常用）



```objc
typedef void (^CompletionBlock)(NSData *data, NSError *error);

// 使用时非常简洁
CompletionBlock handler = ^(NSData *data, NSError *error) {
    NSLog(@"data: %@, error: %@", data, error);
};
```



AFN、SDK 的回调基本都是这种写法。

### 4. Block 作为函数参数（AFN 的本质）



```objc
- (void)requestWithURL:(NSString *)url
            completion:(void (^)(NSData *data, NSError *error))completion {
    // 模拟异步完成
    completion(nil, nil);
}

// 调用
[self requestWithURL:@"https://api.com"
          completion:^(NSData *data, NSError *error) {
    NSLog(@"请求完成");
}];
```



**AFN 的 `success:^(NSURLSessionDataTask \*task, id responseObject){...}` 就是这个结构。**

## 二、Block 捕获外部变量（重点）

Block 会"捕获"它定义时所在作用域的外部变量。

### 1. 捕获局部变量 = 值拷贝，只读

```
int a = 10;
void (^blk)(void) = ^{
    NSLog(@"a = %d", a);   // 能读取
    // a = 20;             // ❌ 编译报错！不能修改
};
a = 30;         // 修改外部 a，不影响 block 内部捕获的 a
blk();          // 打印 10
```



**原因**：block 定义时把 `a` 的值**拷贝**到了自己的结构体里，之后内部读的是拷贝。因为是拷贝且只读，所以不能改。

### 2. `__block` 修饰 = 捕获地址，可以修改



```
__block int a = 10;
void (^blk)(void) = ^{
    a = 20;          // ✅ 可以修改
    NSLog(@"a = %d", a);
};
blk();               // 打印 20
NSLog(@"a = %d", a); // 打印 20（外部也变了）
```



`__block` 让变量从栈搬到一个堆上的包装结构里，block 捕获的是这个包装结构，所以能改、内外同步。

### 3. 捕获对象类型的注意点



```
NSString *str = @"hello";
void (^blk)(void) = ^{
    NSLog(@"%@", str);   // 捕获的是指针（引用计数 +1）
};
```



对象的捕获是**指针拷贝**（引用计数 +1），不是对象内容拷贝。

### 4. 静态变量、全局变量不会被捕获



```
static int sCount = 0;
int gCount = 0;
void (^blk)(void) = ^{
    sCount = 1;   // 直接访问，不捕获
    gCount = 1;   // 直接访问，不捕获
};
```



静态/全局变量本身就在全局区，block 不需要捕获。

## 三、三种 Block 类型（内存分区）

| 类型                | 存储位置 | 特征                                                         |
| :------------------ | :------- | :----------------------------------------------------------- |
| `__NSGlobalBlock__` | 代码段   | 不捕获外部变量（或只捕获静态/全局变量）                      |
| `__NSStackBlock__`  | 栈       | 捕获了局部变量，在 MRC 下存在                                |
| `__NSMallocBlock__` | 堆       | 栈 block 被 `copy` 到堆，ARC 下绝大多数捕获变量的 block 都是这个 |

### 验证

objc

```
// 1. 全局 block：没有捕获局部变量
void (^globalBlock)(void) = ^{
    NSLog(@"global");
};
NSLog(@"%@", [globalBlock class]);   // __NSGlobalBlock__

// 2. 捕获局部变量（ARC 自动 copy 到堆）
int a = 10;
void (^mallocBlock)(void) = ^{
    NSLog(@"%d", a);
};
NSLog(@"%@", [mallocBlock class]);   // __NSMallocBlock__
```



### 关键结论

+ **ARC 下，赋值给强指针的捕获变量的 block，会自动从栈 copy 到堆**，所以大部分 block 都是 `__NSMallocBlock__`。
+ **MRC 下需要手动 `[block copy]`**。
+ 栈 block 出了作用域就销毁，直接调用/保存会崩溃。这就是 AFN 内部为什么要对回调 block 做 copy。

### 需要手动 copy 的场景

objc

```
// 作为属性保存的 block 要用 copy 修饰
@property (nonatomic, copy) void (^completionBlock)(void);
```



**block 属性必须用 `copy`，不能用 `strong`**（历史习惯：copy 能把栈 block 拷贝到堆，保证生命周期）。

## 四、循环引用（项目必踩的坑）

### 1. 循环引用怎么产生

objc

```
@interface MyVC : UIViewController
@property (nonatomic, copy) void (^block)(void);
@end

// 错误写法
self.block = ^{
    NSLog(@"%@", self);   // block 强引用 self
};
// self 强引用 block，block 强引用 self → 循环引用，self 永远不释放
```



### 2. 解决：`__weak`

objc

```
__weak typeof(self) weakSelf = self;
self.block = ^{
    NSLog(@"%@", weakSelf);   // weak 引用，不增加引用计数
};
```



`typeof(self)` 是当前类类型，这样写通用，不用写死类名。

### 3. 为什么有时还要配 `__strong`

objc

```
__weak typeof(self) weakSelf = self;
self.block = ^{
    __strong typeof(weakSelf) strongSelf = weakSelf;  // block 内保活
    if (!strongSelf) return;
    dispatch_after(dispatch_time(DISPATCH_TIME_NOW, (int64_t)(2 * NSEC_PER_SEC)), dispatch_get_main_queue(), ^{
        [strongSelf doSomething];   // 延时期间 self 不会被释放
    });
};
```



原因：`weakSelf` 可能在 block 执行到一半时变成 nil，先 `strong` 一下保证 block 执行期间对象存活。这是**防野指针 + 防中途释放**的标准写法。

### 4. AFN 回调里的标准写法

objc

```
__weak typeof(self) weakSelf = self;
[self.manager GET:url parameters:nil success:^(NSURLSessionDataTask *task, id responseObject) {
    __strong typeof(weakSelf) strongSelf = weakSelf;
    if (!strongSelf) return;
    strongSelf.dataArray = responseObject;
} failure:^(NSURLSessionDataTask *task, NSError *error) {
    NSLog(@"error: %@", error);
}];
```



> `self` → `manager` → block → `self` 也是循环引用，所以回调里必须 `__weak`。

## 五、Block 的底层本质（进阶，了解即可）

Block 本质是一个结构体对象：

c

```
struct __block_impl {
    void *isa;          // 指向 block 的类对象
    int Flags;
    int Reserved;
    void *FuncPtr;      // 指向 block 要执行的函数
};

struct __MyBlock {
    struct __block_impl impl;
    // 捕获的变量列表（值拷贝或指向 __block 包装结构的指针）
};
```



+ `isa` 指向 `__NSGlobalBlock__` / `__NSStackBlock__` / `__NSMallocBlock__`，所以 block 是"对象"。
+ `FuncPtr` 指向真正执行的函数。
+ 捕获的变量以**值**的形式存在结构体里（`__block` 时存指针）。

这也是为什么：

+ 不捕获变量 → 不需要拷贝变量 → 可以放全局区；
+ 捕获变量 → 需要把变量拷进结构体 → 要 copy 到堆管理生命周期。

------

## 六、常见坑总结

| 坑                     | 说明                    | 解决                             |
| :--------------------- | :---------------------- | :------------------------------- |
| block 属性用 strong    | 栈 block 不 copy 会崩溃 | 用 `copy`                        |
| block 内直接改局部变量 | 编译报错                | 加 `__block`                     |
| self 循环引用          | 内存泄漏                | `__weak typeof(self)`            |
| weakSelf 中途变 nil    | 野指针                  | `__strong` 保活 + 判空           |
| MRC 忘记 copy          | 栈 block 提前销毁       | `[block copy]`（ARC 一般不用管） |
| 多线程里改捕获变量     | 数据竞争                | 加锁或串行队列                   |

------

## 七、三个可运行的示例

### 示例 1：从基础到捕获

objc

```
- (void)demo1 {
    // 无捕获
    void (^hello)(void) = ^{ NSLog(@"hello"); };
    hello();

    // 捕获 + __block
    __block int count = 0;
    void (^add)(void) = ^{ count++; };
    add(); add();
    NSLog(@"count = %d", count);   // 2

    // 作为参数
    [self runBlock:^(int x) {
        NSLog(@"传入 %d", x);
    }];
}

- (void)runBlock:(void (^)(int))callback {
    callback(100);
}
```



### 示例 2：循环引用 & 修复

objc

```
// 错误版本（泄漏）
- (void)badExample {
    self.block = ^{
        [self doSomething];   // 循环引用
    };
    self.block();
}

// 正确版本
- (void)goodExample {
    __weak typeof(self) weakSelf = self;
    self.block = ^{
        __strong typeof(weakSelf) strongSelf = weakSelf;
        if (!strongSelf) return;
        [strongSelf doSomething];
    };
    self.block();
}
```



### 示例 3：模拟 AFN 异步回调

objc

```
typedef void (^NetCompletion)(NSData * _Nullable data, NSError * _Nullable error);

- (void)fakeRequest:(NSString *)url completion:(NetCompletion)completion {
    dispatch_async(dispatch_get_global_queue(0, 0), ^{
        sleep(1);
        NSData *data = [@"{\"ok\":true}" dataUsingEncoding:NSUTF8StringEncoding];
        dispatch_async(dispatch_get_main_queue(), ^{
            if (completion) completion(data, nil);   // 回调前判空
        });
    });
}

// 调用
__weak typeof(self) weakSelf = self;
[self fakeRequest:@"https://api.com" completion:^(NSData *data, NSError *error) {
    __strong typeof(weakSelf) strongSelf = weakSelf;
    if (!strongSelf) return;
    NSLog(@"拿到数据: %@", [[NSString alloc] initWithData:data encoding:NSUTF8StringEncoding]);
}];
```
